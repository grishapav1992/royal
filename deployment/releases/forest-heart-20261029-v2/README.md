# Forest Heart production release

User scope: publish only Forest Heart, including the approved v1.7 interface, character animation and audio. Caribbean Treasures and other unpublished main features are excluded.

The source composition preserves the concurrent roulette release `29851103da0f9bbf997d3933d9be005ec7d5d6bf`, now running on production. The first Forest Heart attempt stopped before any application mutation because that release held the publication locks. It preserves the seven payment source files already present on the server and verified against GitHub. Existing 117 module contracts, external packages, payment/reconciliation programs, dependencies, service configuration and data remain in place. The administration entry and assets remain from the parent image.

`prepare.mjs` consumes the clean source commit's standard release manifest and GitHub receipt. It builds a bounded payload and rejects unrelated source differences. The Nile bundle retains thirteen exact historical input blobs. Its separate catalog override adds only Forest Heart to the fourteenth historical input; the builder verifies the entire override against that exact three-line transformation. No other financial catalog behavior changes.

`deploy.py` verifies the production baseline under three existing publication locks. It backs up source, financial source, private configuration and the Nile schema, and tags both previous images. Candidate images extend those exact images. Full inventories reject changes to dependencies, other backend programs or other game packages. It publishes the compatible financial service first, then the host under the existing financial gate, and finally installs the single module with an absent-pointer precondition. Files and directories for the public module use readable permissions. Player data is never restored during publication or failure recovery.

The Forest Heart mathematical model, protocol and server scorer match the reviewed development branch. Qualification was regenerated through the official command, without changing targets, seeds or evidence by hand. This composition verifies twelve qualified profiles and retains the unchanged 114-game legacy baseline. The additional financial test runs all 84 stake/choice combinations through the actual retained financial composition, including bonus recovery and idempotent settlement, on disposable PostgreSQL. The existing ten native financial regression scenarios are bundled with those same retained inputs.

Run the standard `release:plan`, `release:prepare`, and `release:verify -- --github` from the exact source commit after it is saved in main history. Then run `node deployment/releases/forest-heart-20261029-v2/prepare.mjs`. `run-release.py` and its payload are immutable for a release attempt. Post-publication HTTP checks and the pushed SERVER.md record complete publication.

Temporary local files belong to `artifacts/work/forest-heart-ux-v7/`. Remove transport, partial payloads and raw browser/audio artifacts after verification; keep a compact final report. A running local review session retains its temporary database until it is closed. Production backups remain on the server.
