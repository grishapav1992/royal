# Star Spin 1.5.1: полный рост Весперы

Исправлен исходный рисунок, заканчивавшийся на голенях. Обновлены PNG, прозрачный WebP, референс закрытых глаз, области Rive-рига и экспорт Весперы. Остальные три экспортных JSON пересобраны из-за общего хеша `rigs.json`; их бинарные анимации сохраняются. Вёрстка, математика, кошелёк, коллекционный прогресс, аудио и набор доступных игр не изменяются.

Пакет `1.5.1-a6511d3f697d`, API/rules/progress 1/2/1, манифест SHA-256 `288d2c1d84a4c28573d29d64e23ad6f25eda088f9c603ae4334a573f853b537d`. Настоящий host с подключённым чатом проверен на 13 размерах. Отдельно просмотрены все четыре героини, статическая и анимированная Веспера, её мобильный вид и native-кадр моргания.

Установщик основан на предыдущем проверенном выпуске Star Spin. Под тремя штатными блокировками он требует неизменного полного производственного инвентаря: образа, контейнера, исходников, backend, финансовых программ, служб, настроек и указателей модулей. Разрешены только 14 перечисленных файлов игры и новый независимый пакет. Перед заменой сохраняются прежние исходники, указатель, пакет и тег образа. Все медиаресурсы пакета связываются с точными прежними или обновляемыми публичными исходниками. Изменившийся после подготовки сервер блокирует установку.

`verify-inputs.mjs` заново проверяет прежние исключения CRLF и типовой контракт без изменения исполняемого JavaScript. RTP-доказательства не подменяются. Проверки установщика выполняются на Linux, где доступен `fcntl`. После установки обязательны публичная сверка каждого файла, завершённое обслуживание, здоровый host и сохранённая в main итоговая запись.
