# Royal Roulette publication

Publish reviewed European roulette with the felt table, brass wheel, ball motion and original material sounds. The composition starts from the verified application revision 9acf3686965fedc0c81efaaa6f740e30d4fef175 and contains only the roulette feature. Other unpublished main features are excluded from this application build, while their source remains in main. The production composition must be an ancestor of main before release preparation.

Use release:plan, release:prepare and release:verify --github with that explicit base. The wrapper reuses their exact client, backend and roulette package outputs. Non-roulette backend inputs must equal the base Git blobs; existing independently published Stars sources are retained with exact reviewed Git origins. The dependency lock, runtime package metadata, host compatibility contracts, payment/finance programs and other module pointers are preserved.

The installer reuses the guarded skin-walk publication flow: three shared filesystem locks, immutable image overlay, full source backup, tagged previous images, a supervised financial lease through the one game container replacement, and independent full runtime/settings checks. Only index.js may change in the backend. The cover SVG is the only new static public path. Unknown daemon outcomes require explicit reconciliation and do not trigger an automatic second container replacement.

After a healthy compatible host, the existing module publisher installs only royal-roulette under the held locks. Its expected old pointer and package hashes are pinned; a temporary public umask is restored afterward. Other modules, host contract, current database and persistent volumes remain intact. The previous roulette pointer and immutable versions are retained for rollback. A module failure leaves the host compatible and the release incomplete until the module phase is verified.

Tests use disposable local accounts and PostgreSQL. Public checks must verify health, exact index/client/package bytes, old module pointers, anonymous wallet protection and guest desktop/mobile layout without creating production wagers. Do not restore a database over new player operations. Record the source commit, running image, package version and verification in SERVER.md and push that record before calling the release complete. Remove only this task's temporary worktree, contexts, transport and raw captures after GitHub preservation is confirmed.
