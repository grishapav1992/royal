# Улица, крыша и окно третьего этажа

Выпуск переносит проверенную локальную улицу, её жителей, живые окна, пожарную лестницу, крышу и туалет поверх действующих host и backend. Физика маршей сохраняет выбранное вертикальное направление при боковом вводе. На плоской площадке сетевое сглаживание сохраняет её высоту.

Исходный состав зафиксирован в scope.json. Host и backend собираются по отдельным проверяемым проекциям. Новые и возвращённые игры не входят в выпуск. Каталог, математические исходники, кошелёк, принятые операции, независимые модули, настройки и другие службы сохраняются по полному боевому инвентарю.

Цель нажатия на лестницу сохраняется до подтверждённого прибытия на сервере. Если сетевое согласование оставляет персонажа перед площадкой, клиент завершает тот же маршрут после подтверждения предыдущего движения.

Трёхстороннее согласование накладывает только изменения этой ветки на опубликованные исходники. Шесть явно проверенных разрешений сохраняют боевые команды и подписи чата. Опубликованная походка персонажей сохранена; отдельная неопубликованная доработка внимания бармена сюда не включена. Различающийся исходник английского словаря backend закреплён в проекции прежней версией. Его происхождение подтверждено манифестом прежнего выпуска и точным хешем работающего backend.

Подготовка, проверки и загрузка проходят без общих замков production. Готовый установщик получает все три замка неблокирующим способом, освобождает частично полученный набор при занятости и возвращает код 75. Операция release повторно сверяет живую основу, сохраняет откат и использует существующие финансовые барьеры. Автоматического ожидания или повторного запуска публикации нет.

После установки обязательны публичная проверка файлов, каталога и отказов прямого запуска, проверка маршрута улицы и завершённое штатное обслуживание. Статус публикации фиксируется отдельно в verification.json и deployment/SERVER.md.
