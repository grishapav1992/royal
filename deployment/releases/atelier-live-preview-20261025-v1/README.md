# Interactive skin fitting room

Two designs are offered for new orders. A focused local canvas in the atelier dialog uses the game renderer to let players walk, turn and sit before permanently selecting one design. Legacy paid three-design orders keep their candidates. No provider model, price, wallet rule, game mathematics, module package, backend byte, environment or player data changes in this release.

Prepare from the verified production revision in SERVER.md using release:plan, release:prepare and release:verify --github. The installer derives from the existing guarded application installer. It holds all three shared publication locks, verifies the exact current source and runtime inventories, archives the complete existing source, pins both previous images and builds an overlay containing only new client bundles and their index. Recovery refuses any later source, runtime, configuration or module change.

The source archive is streamed with a hard compressed-byte limit. Its budget retains 5 GiB plus three copies of the exact client delta and an 8 MiB margin. An oversized partial archive is removed before source or runtime mutation. Every archived member is compared with the complete reviewed source inventory. Free space is checked again before and after the overlay build and after publication. The temporary Docker context uses hard links to the verified payload, so it allocates no duplicate bundle bytes. An interrupted release can reuse only a complete verified source archive, matching index and both rollback image tags before any build result exists. No existing backup, image or volume is removed.
