# Independent hall elevator

Publish only the 13 elevator source additions/changes and their host/backend
outputs. Keep the exact current production catalogue, wallet, mathematical rules,
accepted rounds, independently published modules, runtime settings and data.

`configure.py` overlays the committed elevator delta and its reviewed audio fix
onto Git-backed source origins matching the production inventory. Existing
production customizations stay intact, including the backend's inherited English
dictionary. Unknown inputs and ambiguous source patches stop preparation.

Run release plan, prepare with both tracked projections, and verify with GitHub.
`prepare.mjs` binds the exact resulting client and backend bytes to the manifest.
The installer reuses the guarded application publisher with all three locks,
source backup, previous image tags, financial quiescence and complete runtime,
service, module and settings inventory checks. Only the game container restarts.
It does not restore a database, update game packages or change environment files.

Before publishing, verify real local connected host travel on desktop and phone,
the motor envelope regression, direct floor selection, independent visitors,
stairs and cancellation. After public HTTPS and browser checks, push the server
record and run the required automatic retention service to completed status.
