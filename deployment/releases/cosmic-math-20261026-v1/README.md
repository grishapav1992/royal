# Cosmic mathematics release

This release restores the qualified Cosmic purchased-bonus origin validator and publishes only the Cosmic client. It preserves the currently installed Mortal Kombat release and other game clients.

Use the verified current production commit as the application manifest base. Prepare from a clean committed checkout, push source and helpers to main, and verify the exact artifact bytes with GitHub before installation. The application and helper commits are recorded independently in the generated manifests.

The installer retains the existing three publication file locks, three continuous financial SQL locks, nonce acknowledgement, explicit transaction completion and recovery checks. SQL drain, held transaction, critical command and final exit limits are unchanged from the reviewed publisher.

The publication supervisor and its two bounded priority helpers are included in the same Git object proof as the installer. They temporarily select only Docker, containerd and the exact reviewed current or candidate game container. Each lease has an independent watchdog, a terminal cancellation marker, opened-file identity checks and an 1800 second limit. Financial-service settings are never selected. The supervisor releases its leases after the installer exits; verify remaining weights explicitly. Candidate-only offline containers use explicit CPU shares with a read-only filesystem and no network.

The preparer refuses unrelated runtime source changes. Cosmic qualification tools and evidence accompany the validator. The complete dependency lock must remain unchanged. The decoder package bytes are checked against the running inventory, and dependency replacement is forbidden in this release.

Only studio-cosmic-escape is an allowed client package. Existing host programs, finance services, configuration, module contracts, previous client URLs and game_data remain protected by the before snapshot. Source and wallet backups and the previous image are retained. Recovery never restores the live database.

The new source rollback archive contains every existing path this transaction can overwrite. New paths are recorded by the change manifest and removed on rollback. Unchanged source is never overwritten by rollback and is still verified against the complete before fingerprint. Existing full production source archives and financial backups remain intact. This avoids allocating another full project archive for a small mathematics patch.

Run the publisher Python tests, Node quiescence tests, RTP gate and relevant Cosmic mathematical, wallet and compatibility checks. Cosmic policy and qualification remain in docs/game-math/qualifications/cosmic-v3.json. The source hash must match that evidence; no evidence or legacy baseline is rewritten to admit a different validator.

Build and verify the candidate against the current production baseline. After installation, verify the live backend, Cosmic pointer and package files, health, wallet protection and host behavior, then push the deployment record.
