# Восстановление связи с залом

Выпуск исправляет зависшее отключение после сетевой паузы и штатного перезапуска сервера. Производственная основа: `f2be9fd0c951c4fb5c380207bcf2308d0ba1dbe4`, проверенные исходники выпуска: `99aa9ac67c7a7f4a0825ced87440c0ee708764a5`.

Обычная серверная резервация в 20 секунд была короче расписания повторов SDK, которое могло занимать 56,2 секунды без учёта сети. После исчерпания повторов клиент удалял ещё действующий токен. Код штатного перезапуска также завершал подключение без автоматического входа. На прежнем клиенте реальный локальный зал остался отключён после 31 секунды без сети. После исправления он восстановил того же игрока и ту же комнату после 31 и 75 секунд.

Теперь обычная резервация действует 90 секунд, активный PvP сохраняет прежние 60 секунд. SDK распределяет повторы внутри этого окна. После завершения повторов или штатного перезапуска клиент автоматически восстанавливает сессию, затем при подтверждённом истечении резервации может войти заново. Срок запуска новых попыток ограничен двумя минутами, каждый HTTP-запрос подключения ограничен десятью секундами, включая тело ответа. Отказ авторизации и явный выход останавливают восстановление. Платные запросы и сообщения чата не повторяются.

Проверенный пакет меняет семь исходных путей, два клиентских файла и основной backend. Проекции фиксируют точное происхождение каждого входа из Git. Все остальные входы сверены с опубликованной основой, включая сохранённый словарь backend. Игровые пакеты, каталог, прямые запуски и приём новых раундов сохраняют прежнюю доступность 19 игр. В этот выпуск игры не добавлялись и не возвращались. Финансовые правила, математика, настройки и постоянные данные сохранены.

Окончательная сборка проверена в настоящем host с чатом на 1440x1000 и 390x844. Принятая минимальная ставка в десять центов пережила перезапуск backend с задержанным ответом кошелька: остались открыты игра и чат, зарегистрированы ровно один запрос и одно списание. Закрытие и повторное открытие не создали новый дебет. После установки прошли 25 публичных HTTPS-проверок и гостевой браузер на обеих ширинах без ошибок JavaScript и горизонтального переполнения. Производственные аккаунты, ставки и сообщения для проверки не создавались.

Точный физический источник старого обрыва установить нельзя: исторического журнала причин закрытия не было. Новый журнал сохраняет этап, код закрытия, время работы процесса и число подключений без имён, почты и токенов. Замеры VPS показали 60-70 процентов CPU steal, то есть ожидания процессорного времени у хостинга. Это отдельное ограничение инфраструктуры, которое данный выпуск не устраняет. Политика восстановления не гарантирует доступность сети или ресурсов VPS.

Порядок дальнейшей диагностики описан в [docs/lobby-connections.md](../../../docs/lobby-connections.md). Результат установки, обслуживания и уборки находится в [verification.json](verification.json).
