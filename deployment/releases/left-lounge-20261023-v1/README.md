Shared geometry moves client art, server interactions, staff routes, cat surfaces and the minimap together. Windows use one row with equal spacing; duplicate windows are removed and wall signs and lights leave the frames clear.

The release overlays the verified PvP/atelier production host. It changes only the reviewed source paths, client files and main backend bundle. Existing game packages and external pointers, payment and finance programs, environment, mounts and player data are preserved. The current source snapshot, prior client index and previous image form the single rollback set.
