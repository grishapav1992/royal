# Star Spin: свободный выбор героинь

Все четыре героини доступны существующим и новым профилям. Задания, жетоны и цены убраны из интерфейса. Исторические записи и любимая героиня каждой стороны сохраняются. Новые ответы на задания отклоняются; повтор ранее принятого UUID возвращает первоначальный результат.

Исходная основа работающего host: `820e1c4e92eeb54b85915c483dc4e59829679c71`. Полная проекция прежнего backend воспроизводит SHA-256 `7b11acb06fdbc5ff43a9cd18f9bdf5a687ca11ccd086562508150a48a9d6684a`. Новая проекция заменяет только `server/starSpinCollection.ts`. Сохранён прежний backend-словарь en, ранее явно зафиксированный в lobby-connection. Другие входы сравниваются с полным production-снимком. Клиент host не меняется. Неизменённые финансовые программы и сервисы остаются в родительском образе.

Установщик использует существующие guards приложения, резервную копию, полный runtime-инвентарь, финансовый барьер и три общих замка. После здорового backend штатный publisher переключает только Star Spin на `1.6.0-f5f4b043e981`, контракт 1/2/1. Полная повторная сверка разрешает только новый неизменяемый пакет и его указатель. Ошибка активации модуля сохраняет совместимый здоровый backend; `finish-module` допускает повтор только при точном совпадении проверенного приложения и прежнего либо нового указателя. Сторонние изменения останавливают повтор. Новых и возвращённых игр нет.

До выпуска пройдены 26 серверных проверок, включая 19 обязательных проверок кошелька, квалификация девяти ставок и 2304 полных replay, а также три браузерных сценария с реальным host и подключённым чатом. Проверки подготовленных байтов и итог production фиксируются отдельно в verification.json. Недоступная общая карта не использовалась как доказательство: зависимости проверены непосредственно по исходникам и полным инвентарям.
