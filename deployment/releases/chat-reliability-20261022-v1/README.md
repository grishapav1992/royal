# Chat provider reliability release

The reported ordinary phrase `Все гуд итс вери гуд` timed out on the previous codex.sale / gpt-6-luna path even with a 12-second diagnostic allowance. This backend update separates public chat classification from the NPC model. When the existing Venice key is available, chat uses qwen3-next-80b and retries a failed attempt with mistral-small-3-2-24b-instruct. The normal primary attempt has 2.5 seconds; both attempts share the existing six-second deadline, including response bodies. A valid verdict is never retried. Exhausted, incomplete or malformed responses remain unpublished and never become an offense.

Optional CHAT_MODERATION_PROVIDER selects venice or codex-sale. CHAT_MODERATION_MODEL and CHAT_MODERATION_BACKUP_MODEL override chat models. Repeating the primary model as the backup disables model failover. Missing selected credentials fail closed in production. Development without credentials retains its existing minimal filter. No production environment file is changed. NPC and Mira settings remain independent. Requests keep user text outside system instructions and require a final strict boolean JSON verdict. Diagnostics contain only provider, model, failure kind, HTTP status and elapsed time, without player identifiers, text, responses or credentials. Neutral questions about a quoted insult receive explicit conservative examples in the existing policy.

The only changed runtime program is /app/dist-server/index.js. The three current host entry files are included with exactly their previous bytes to reuse the guarded publication helper. All other runtime files, URLs, modules, dependencies, configuration, persistent data and services are inherited and verified. This release changes no browser layout or chat protocol.
