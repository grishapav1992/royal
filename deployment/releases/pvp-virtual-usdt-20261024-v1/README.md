# Common virtual USDT for PvP

The user explicitly replaced the earlier Nile requirement on 24 October: all new games and atelier purchases use the existing freely topped-up virtual USDT journal. No blockchain address or transfer is required. Old Nile journals and services remain available for historical reconciliation and already accepted liabilities; no funds are copied between the ledgers.

Six table games use the same balance as slots. Stakes are 1 to 500 USDT in increments of 0.10, so the exact 5% commission on a two-player pot always fits the wallet's cents. Every permitted stake and settlement outcome is exhaustively qualified; this proves aggregate pot accounting, not either player's chance of winning. A reserved bank protects the winner's payout capacity until settlement.

New browser requests have an explicit virtual wallet scope and a distinct recovery key. An old Nile request is rejected instead of being replayed against the virtual balance. Atelier jobs record their payment source; unfinished historical jobs retain their original provider.

The installer preserves all source and runtime files outside the reviewed delta, settings, persistent data, independent packages and other services.
