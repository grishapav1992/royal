# Путь дракона

**Сценарное демо заменено серверной игрой на общем виртуальном балансе Royal.** Квалификация и штатная локальная сборка прошли. Для игры нужен хост и сервер из совместимой рабочей копии. Реальные деньги, пополнение и вывод модуль не обслуживает. На боевой сайт изменения не выкатывались.

## Подключение

`entry.ts` получает совместимый `GameHostV1`, задаёт общее название и передаёт в `mountPanda` команды фасада, снимки игры и звук Royal. `wallet-binding.ts` преобразует подтверждённое сервером поле в `PandaView`. Экран не генерирует символы, не рассчитывает выплату и не держит отдельный баланс. Версия представления 2 не допускает загрузку старого сценарного пакета в новом хосте; версия серверных правил остаётся 1.

Карточка находится в общем каталоге Royal Games под названием **«Путь дракона»**. Новый физический автомат не нужен. Ручная ставка от 0.10 до 50.00 принимает точку и запятую; девять пресетов и проверка суммы используют общую систему. Ставка относится ко всему раунду. Два бонусных действия бесплатны. Панель «Текущий раунд» показывает расход и итоговый возврат только из подтверждённого снимка. При потере ответа общий клиент повторяет прежний UUID, в том числе после закрытия и повторного открытия окна.

Экран сохранён на React. В `public/assets/panda-dragon/` лежат 13 используемых WebP, полученных из экспорта проекта Lovable. Во время игры изображения обслуживает Royal. Права на публичное распространение не проверялись.

## События и обратная связь

- Обычный спин и бесплатное вращение запускают нейтральное движение, а подтверждённое поле отображается после остановки барабанов. Выигравшие линии и столбцы подсвечиваются по серверным позициям.
- Вход в бонус и выбор награды показываются по разрешённым действиям снимка. Частичный возврат, возврат ставки и положительный итог различаются; восстановления и повторные ответы не проигрывают награду заново.
- Пауза, отключение звука и закрытие гасят звуки модуля. Настройка уменьшенного движения убирает длительные эффекты.

## Проверки и запуск

Правила, точное округление, общий HTTP-кошелёк, валидация клиента, повтор UUID при потерянном ответе и оба бонусных выбора проверены на временной базе. [Модель и статус квалификации](../../docs/game-math/dragon-path-v1.md) описывают фактические результаты и границу допуска.

```bash
node --import tsx scripts/database-test.ts --import tsx --test server-tests/dragon-path-rules.test.ts server-tests/dragon-path-wallet.test.ts
```

Соберите Royal штатной командой, затем запустите браузерные проверки на собранном модуле и отдельной временной базе:

```bash
npm run build
```

```bash
npm exec playwright test -- --config=playwright.panda.config.ts
```

**Четыре сценария Chrome прошли.** Настольный сценарий проверяет виртуальное списание 0.10, потерю ответа после записи, повтор того же UUID и восстановление при повторном открытии окна с чатом. Узкие окна 390 и 320 пикселей проверены с мобильным чатом и уменьшенным движением. Проверен английский интерфейс. Серверные проверки отдельно покрывают оба бонусных выбора независимо от выпадения бонуса в браузере.
