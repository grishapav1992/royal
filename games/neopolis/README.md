# Стражи Неополиса / Guardians of Neopolis

Локальный игровой прототип `studio-neopolis`: независимый клиентский пакет, host API 1, правила 1, прогресс 1. Добавлен в реестр модулей, каталог и зал. Прежние автоматы сохраняют координаты. Интерфейс, правила, таблица выплат, доступные названия и сообщения поддерживают русский и английский через язык Royal.

## Механика

Поле 5×4, 40 фиксированных линий. Совпадения от трёх символов слева направо; WILD заменяет обычные знаки. На линии оплачивается старшая комбинация. Каскады ограничены восемью выигрышными показами для исходного поля и после каждого умения. Последний оплаченный показ цепочки не заполняется неоплаченными символами.

Игрок выбирает стартового героя. Для двух остальных нужны три эмблемы связи. Эмблемы накладываются поверх обычных символов и собираются один раз. Эмблема доступного героя, включая последнюю открывающую, ставит его способность в очередь. Каждый герой действует максимум один раз за оплаченный спин со всеми его каскадами. При нескольких ожидающих героях приоритет: Гранит, Призма, Импульс.

* Гранит / Granite: удаляет обычные символы области 2×2 с падением оставшихся.
* Призма / Prism: заменяет до пяти обычных символов в случайных позициях.
* Импульс / Impulse: превращает один из трёх центральных барабанов в WILD. Символы Нуля сохраняются.

Собранная команда разрешает появление символов Нуля / Null. Три символа на одном показе открывают 10 бесплатных вращений. Спин с одной или несколькими активациями героя снимает один сегмент щита. После трёх сегментов, со следующего спина, способности усиливаются: 3×3, до восьми замен и WILD-колонна ×2 для линий, использующих её. Следующие три спина с активациями разрушают узлы. Победа единожды создаёт центральную WILD-колонну ×2, разрешает её каскады и добавляет три вращения. Все выплаты сохраняются при завершении бонуса без победы.

## Общие службы и сохранение

Модуль получает готовые `expansionClient`, `demoWallet`, язык, звук и реакции через `readGameHost()`. Отдельного клиентского кошелька нет. Результаты создаются серверным `crypto.randomInt`. Ответ содержит только уже использованные случайные значения; проверка повторяет расчёт всех показанных кадров и выплат. Клиент не задаёт поле, прогресс, награду или будущую случайность.

`server/games/neopolis.ts` включён в существующий `DemoExpansionStore`. Платный спин и бонус используют общий журнал PostgreSQL, блокировку аккаунта и UUID операции. Каждый обычный спин рассчитывается один раз. Бонус продолжается бесплатным `neopolis-spin` с номером ревизии. Повторы UUID не списывают ставку и не создают вторую выплату. Незавершённый бонус и неопределённый запрос восстанавливаются штатными службами Royal. Старые клиенты не получают новые сессии без `X-Royal-Neopolis-Rules: 1`.

Команда переносится из последней завершённой серверной сессии. До конца цикла ставка и первый герой фиксированы, поэтому нельзя собрать прогресс на дешёвой ставке и перенести его на дорогую. Бонус выплачивается в конце целиком, команда сбрасывается после его завершения. Денежные расчёты выполняются в целых минимальных единицах через BigInt. Ставки: 10, 20, 50, 100, 200, 500 демомонет. Предел одного раунда: 3000 ставок, с завершением цикла при достижении. История, кошелёк и прогресс привязаны к аккаунту.

Таблица выплат пока экспериментальная. RTP не рассчитан и не сертифицирован. Прототип доступен через общий тестовый кошелёк; платёжные whitelist не расширяются. Продуктовые изображения пока представлены собственными векторными персонажами и символами. Автовращения и покупка бонуса не входят в этот этап.

## Сборка и локальный просмотр

Команды выполняются из корня рабочей копии:

```powershell
npm --prefix games/neopolis run build
node --import tsx scripts/neopolis-preview.ts
```

Русская версия: http://127.0.0.1:5216/tests/fixtures/neopolis-preview.html?lang=ru

Английская версия: http://127.0.0.1:5216/tests/fixtures/neopolis-preview.html?lang=en

Стенд создаёт отдельную временную PostgreSQL, запускает настоящий API Royal, создаёт локальный тестовый аккаунт и загружает собранный пакет штатным `IndependentGameUI`. `.env` не читается. Production не используется. При остановке стенда тестовая база удаляется. Кнопка в верхней полосе переоткрывает модуль для проверки восстановления. Полоса стенда не входит в игровой пакет.

Клиент собирается штатным `build-game-module.mjs`, включая SHA-256 манифест и неизменяемую версию. Первый выпуск требует совместимого обновления host, поскольку добавлены новый серверный движок, каталог и заголовок протокола. Последующие визуальные обновления могут выпускаться отдельно по `docs/game-modules.md`.

## Проверки

```powershell
node --import tsx scripts/database-test.ts --import tsx --test server-tests/neopolis-math.test.ts server-tests/neopolis-wallet.test.ts server-tests/dracona-wallet.test.ts
node --import tsx --test server-tests/independent-modules.test.ts server-tests/neopolis-catalog.test.ts
node node_modules/@playwright/test/cli.js test --config playwright.neopolis.config.ts
npm run build
```

Проверяются реальные способности и каскады, полный цикл с победой и без неё, эмблемы из каскадов финальной атаки, неизменность входного состояния, отклонение подменённых выплат и кадров, сохранение команды, фиксация ставки, чужой аккаунт, устаревшая ревизия, конкурентные повторы, одно итоговое начисление и восстановление бонуса. Браузер проверяет RU/EN, пять размеров экрана, правила и таблицу выплат, потерянный HTTP-ответ, переоткрытие и перезагрузку бонуса через настоящий API и временную PostgreSQL. Дополнительный сценарий входит в живой зал через Colyseus, подходит к автомату из каталога, делает ставку и проверяет настоящее окно Royal с подключённым чатом на 1440×1000 и 390×844, затем возвращается в зал. Основное окно, масштабирование и чат не изменены.

Проверено 22 октября 2026: полная сборка приложения и всех 113 модулей, проверка SHA-256 всех пакетов, 22 серверные проверки и 3 браузерных сценария проходят. Пакет Neopolis: `0.1.0-72410ad31b3d`. Снимки экрана находятся в `test-results/neopolis/review/` локального стенда.

Расширенный прогон `studio-layout.test.ts` и `casino-expansion.test.ts` выявляет девять прежних ошибок: устаревшие ожидания планировки и состава каталога, попытки начать удалённые карточные игры и кодировку временной PostgreSQL под Windows. Те же девять ошибок воспроизведены на чистом исходном коммите `4cd5383`, без Neopolis. Снимок и журнал сравнения сохранены локально в `artifacts/neopolis-baseline-20261022/`. Эти старые проверки не исправлялись в рамках прототипа.
