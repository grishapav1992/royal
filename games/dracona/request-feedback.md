# Request feedback

Input closes the two inner doors of the cabinet before the shared wallet request. While the request is unconfirmed the doors stay closed and only the light between them pulses in a neutral 900 ms loop. This is a presentation choice with no new grid, probability, reward or sound. The closing movement runs in parallel with the request. After the confirmed response the cast starts, the doors open and the confirmed field falls.

The iframe owns the loop. Pause, either document becoming hidden, and close stop it. Resume may show the current pending request but never replays a result. Reduced motion keeps the doors open and the board still with the existing action status. An unconfirmed request opens the doors over the previous field, and the shared recovery helper reserves Check for a stopped unconfirmed operation. Verify closed doors while a response is held, no recovery button during a normal request, and normal confirmed playback after release.
