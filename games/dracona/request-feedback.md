# Request feedback

The existing waiting phase starts on input, before the shared wallet request. During it the previous symbol artwork moves downward in a neutral 600 ms loop. This is a presentation choice, with no minimum server wait and no new grid, probability, reward or sound. The confirmed response replaces the waiting phase with the existing spin and event sequence.

The iframe owns the loop. Pause, either document becoming hidden, and close stop it. Resume may show the current pending request but never replays a result. Reduced motion keeps the board still with the existing action status. The shared recovery helper reserves Check for a stopped unconfirmed operation. Verify visible incoming motion while a response is held, no recovery button during a normal request, and normal confirmed playback after release.
