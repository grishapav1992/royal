# Дракона: Наследие Малфоев

Независимый модуль `studio-dracona`, API 1, правила 2, прогресс 1. Визуал перенесен из согласованного локального прототипа, включая прозрачную героиню, плавные переходы, две стойки, взмах, каскады, шкаф и автовращения. В выпуск входят только обычные одетые позы.

## Общие службы Royal

Кошелек, аккаунт, транспорт операций, повтор потерянного запроса, язык и звук предоставляет host. Модуль не создает отдельный кошелек и не рассчитывает исходы в браузере. `server/games/dracona.ts` использует общую сессию `DemoExpansionStore`, ее блокировку аккаунта и журнал операций PostgreSQL. Повтор одного UUID не создает вторую ставку или выплату.

Одна начальная ставка открывает серверный раунд. Если выпал бонус, бесплатные вращения, руны и уже накопленная выплата сохраняются в той же сессии. Итог всей серии поступает в общий тестовый кошелек после завершения бонуса. Перезапуск модуля восстанавливает последнюю подтвержденную сессию, неподтвержденный запрос повторяется с прежним UUID.

Интерфейс изолирован в iframe внутри существующего окна Royal. Подключенный чат остается в host. Размер iframe следует за доступной областью игры, общая система масштабирования не изменяет ее координаты. Закрытие удаляет обработчики, анимации, таймеры, аудиоподписку и ResizeObserver, сохраняя общую операцию кошелька.

## Механика

Поле 5 × 4. Группы из пяти соседних одинаковых символов дают выигрыш. До восьми каскадов и трех обменов участка 2 × 2 с резервом за спин. Три герба на одном показе открывают восемь бесплатных вращений. Повтор добавляет два, максимум 20 за бонус. В бонусе перенос гарантирован; руны его клеток сохраняются и растут до ×5. Для группы берется наибольшая руна. В 45% бесплатных вращений резерв содержит четыре одинаковых обычных символа.

Ставки: 10, 20, 50, 100, 200 или 500 демомонет. Автосерии по 10, 25 или 50, отдельная обычная, быстрая и турбо-скорость. «Стоп» завершает текущий спин и отменяет остаток. Бонусное окно и ошибки останавливают серию.

Клиент проверяет показанные кадры и выплаты повторением уже использованной сервером случайной последовательности. Будущие исходы и будущая случайность в ответ не входят. Предельная ответственность раунда ограничена проверенным верхним математическим пределом 100000 ставок.

## Проверки и сборка

`npm --prefix games/dracona run build`

Проверки механики, протокола и автовращений находятся в `server-tests/dracona-*.test.ts`. Проверки кошелька запускаются через `scripts/database-test.ts` на временной PostgreSQL.

Для воспроизводимого расчета с `seededRandom(5)` ставка 100 дает 225 монет. `seededRandom(1)` открывает восемь бесплатных вращений; полная серия дает 7445 монет. Локальный браузер с настоящим подключенным чатом проверил закрытие и повторное открытие бонуса, его продолжение, автовращения и мобильную остановку.
