# Star Spin: Rive

Первая версия анимации четырёх героинь, 1 ноября 2026. Пользователь выбрал работу через Rive. Локальная сборка не загружает проект в Rive Cloud и не требует покупки подписки.

Записи из настоящего окна коллекции: [Лира](../../../docs/concepts/wild-nudge/rive-lyra.webm), [Аэлири](../../../docs/concepts/wild-nudge/rive-aeliri.webm), [Веспера](../../../docs/concepts/wild-nudge/rive-vespera.webm), [Никсара](../../../docs/concepts/wild-nudge/rive-nyxara.webm).

## Исходники и сборка

- `rigs.json`: области деформации, устойчивые части позы, индивидуальные циклы и амплитуды.
- `<id>/scene.rml`: полноценный Rive-проект с пятью костями, пятью текстурными сетками, семью timelines, ViewModel и машиной состояний.
- `<id>/blink-reference.png`: закрытые веки, подготовленные встроенным image_gen с сохранением исходной позы. В игру попадает только небольшой кроп `eyelids.png`. Промпты сохранены в `prompts.json`.
- Основная текстура: утверждённый `public/assets/wild-nudge/characters/<id>.webp`. Лицо и опора позы закреплены; дыхание, волосы или отростки, ткань и рука или оружие деформируются раздельно.
- `scripts/build-star-spin-rive.mjs`: воспроизводит RML, проверяет компиляцию и отсутствие проблем inspect, делает настоящий native-кадр и экспортирует данные с SHA-256 исходников.

Используется Rive CLI **1.7.0**. Официальная Windows-сборка 1.8.0 на этом ПК завершалась с `0xC0000005` до открытия проекта. Версия закреплена; автоматического обновления нет. CLI вызывается напрямую из `%USERPROFILE%/.rive/versions/1.7.0/rive.exe`, существующая общая команда `rive` не изменяется. На другом ПК путь задаётся через `ROYAL_RIVE_CLI`.

```powershell
node scripts/build-star-spin-rive.mjs
node scripts/build-star-spin-rive.mjs --character lyra
node --test server-tests/star-spin-rive-assets.test.mjs
node scripts/build-game-module.mjs --game wild-nudge
```

Для прямой работы с отдельной сценой использовать закреплённый CLI: `rive <project> --verify`, `rive inspect <project> --summary`, `rive <project> --screenshot --advance=1`. Изменения генератора или `rigs.json` требуют повторной сборки экспортов. Редактирование RML вручную будет заменено генератором. Экспорт редакторского `.rev` и облачная публикация отдельно требуют входа; они не выполнялись.

## Индивидуальность

| Героиня | Движение | Цикл ожидания |
| --- | --- | --- |
| Лира | Раскрытая рука Силы, волосы и край накидки | 5 с |
| Аэлири | Медитация с устойчивыми ногами, отростки и парящий меч | 7 с |
| Веспера | Сдержанный акцент руки у бедра, хвост волос и тяжёлый плащ | 6 с |
| Никсара | Устойчивая боевая стойка, волосы, ткань и хват меча | 4,5 с |

Это художественные параметры первой версии, не научные пороги и не измеренная оценка приятности. Большие повороты головы, смена ракурса и новая мимика помимо моргания требуют дорисованных частей. Их нет в текущем риге.

## Контракт игры

ViewModel `Character`, числовое свойство `mode`, StateMachine `Character`:

| mode | Состояние | Источник |
| --- | --- | --- |
| 0 | idle | Ожидание |
| 1 | spin_wait | Запрос и показ барабанов |
| 2 | wild_align | Подтверждённый шаг совмещения WILD |
| 3 | bonus_enter | Подтверждённый вход в бесплатную серию |
| 4 | bonus_idle | Сохранённая активная серия |
| 5 | round_win | Выплата полного оплаченного раунда выше его ставки |
| 6 | select | Подтверждённый выбор видимой героини; короткое приветствие после первой загрузки |

Повторные ответы и восстановление не создают очередь старых реакций. Только текущий ручной выбор может дождаться загрузки рига в пределах 10 секунд; скрытие, пауза и смена героини отменяют приветствие. Отдельная денежная логика или звук внутри Rive отсутствуют. Старт вторичных персонажных жестов привязан к существующей общей аудиошкале Star Spin; отдельное совпадение пика жеста со звуковым пиком не измерялось. Все четыре сцены используют один контракт, при расширении нужны новые иллюстрация, конфигурация, веки и экспорт.

В игре работает один Rive instance для выбранной героини. Он перемещается между её карточкой и областью рядом с барабанами. Скрытые области, пауза, настройки и скрытие страницы останавливают воспроизведение. Уменьшенное движение и ошибки загрузки оставляют статическую иллюстрацию. Закрытие освобождает instance, canvas, наблюдатель размеров и собственные таймеры.

Экспорты и WASM передаются локальными JSON-ресурсами существующего независимого модуля. SHA-256 и размер проверяются до загрузки. CDN, blob URL, сетевые Rive-скрипты и отдельный кошелёк не используются. Совместимость host API, rules и progress остаётся 1/1/1; версия пакета 1.3.0.

Runtime: `@rive-app/webgl2` **2.49.0**, лицензия MIT. Уведомление поставляется в `rive-runtime.json` вместе с WASM. [Официальный исходник лицензии](https://github.com/rive-app/rive-wasm/blob/master/LICENSE).

Star Spin остаётся неопубликованным прототипом. Этот этап не включает его в production-каталог и не решает отдельную миграцию на общие ставки 0,10 USDT.
