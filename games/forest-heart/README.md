# Forest Heart client 1.15

The approved client uses the existing video-v3 nod, board glance and crystal gesture. Each lasts three seconds, separated by six seconds of quiet idle. Video texture coordinates are fixed: there is no geometric endpoint processing, added head rotation, breathing deformation over video, or separate eye overlay. Native idle keeps subtle breathing, hair and cloth at 25% intensity.

The module retains host API 1, rules 1 and progress 1. The same host owns transport, wallet, sessions, language and audio. Field reactions, rules, paid costs and payout mathematics are preserved. Pause, hidden pages, reduced motion, unavailable media and close retain their stop and fallback behavior. The larger receiver flowers and responsive scene use the real host with connected chat.

Source poses differ at the beginning and end. The existing premultiplied blend can reveal this mismatch. These files retain the earlier 5/3 time compression of paid five-second generations. No new generation is part of the update.

[Source provenance](../../docs/concepts/forest-heart/video-v3-assets.json) and [rendered verification](../../docs/concepts/forest-heart/stability-v15-review.json) record inputs and limitations. The comparison artifact shows the pre-processing source on the left and rejected endpoint deformation on the right. Historical experimental assets and preparation tooling remain in the feature branch rather than this release.
