# Записи пользователя для победных серий Afterglow

Три предоставленных пользователем MP3 скопированы побайтово в public/assets/afterglow/audio/v2/win-1.mp3, win-2.mp3 и win-3.mp3. Содержимое не редактировалось и не прослушивалось. Исходные имена, размеры и SHA-256 сохранены в public/licenses/afterglow-user-audio.json. Лицензия CC0 на эти файлы не заявляется. Ранее подключённые записи v1 сохраняют свой отдельный manifest.

Победная запись выбирается случайно после подтверждённого завершения раунда с выплатой от 5 ставок либо начиная с третьего прибыльного раунда подряд. Прибыль означает выплату больше общей ставки за раунд. Проигрыш и возврат ровно ставки обнуляют серию. Все бесплатные продолжения бонуса считаются одним раундом. Повтор одного подтверждённого раунда не увеличивает серию и не повторяет реакцию. При смене аккаунта серия сбрасывается. Параметры серии относятся только к оформлению, не меняют вероятности или кошелёк.

Три пользовательские записи используются только для побед. Обычные смешки v1 остаются для бонусных событий, Congratulations остаётся для нового образа. Одновременно звучит одна голосовая запись. Победная запись имеет приоритет, не обрывается новой прокруткой и не перекрывается поздравлением. Повтор той же записи подряд исключается, если доступна альтернатива. При единственной загруженной записи разрешён повтор, чтобы звук не исчезал после ошибки загрузки других файлов. Никаких новых записей не создаётся.

Общий выключатель игры, отдельные голосовые настройки, скрытие страницы, смена аккаунта и закрытие останавливают голоса. Автоматического повторного запуска старой записи после возврата нет. Прослушивание в настройках использует обычные смешки v1. Вращение и остановка сохраняют прежние музыкальные эффекты.

Исправлены три проблемы ревью: реакция обрабатывается до итогового окна бонуса; выбор единственной доступной записи не блокируется; запросы альбома ограничены 10 секундами, после ошибки доступно обновление. Победная реакция не ждёт ответа альбома.

54 автоматические проверки прошли, включая прежнюю математику, кошелёк, прогресс и новые сценарии серии, одиночной доступной записи, приоритетов и отмены альбома. Браузерная проверка использует беззвучные технические заглушки вместо трёх присланных файлов. Проверяются пути, события и отсутствие наложений, без прослушивания записей. Обычный пользовательский предпросмотр обслуживает исходные MP3 после отключения заглушек. Сверяются SHA-256 HTTP-ответов и исходников.

Математические движки, серверный денежный учёт и транспорт кошелька не изменялись. На сервер публикации эта локальная версия не переносилась.
