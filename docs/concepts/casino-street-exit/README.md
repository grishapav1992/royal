# Выход казино на улицу

Проём находится в нижней стене первого этажа, в прежней точке (180, 1300). Бордовая плоская плашка заменена разрывом стены с каменным порогом, раскрытыми по бокам стеклянными створками, ковриком Royal и парой светильников. За порогом видны только плитка и снег, соответствующие улице у входа. Рисунок сохраняет плоскую 2D-геометрию. Напольный слой и стойки проёма разделены по глубине.

Условия прохода, точка появления и размеры зоны перехода не менялись. Обычная ходьба S из зала и W обратно, а также вход по клику используют существующие переходы. Локально проверены оба направления на Chrome 1440x1000 и мобильной эмуляции 390x844. Финальная собранная версия дополнительно проверяется перед установкой.
