# Выход из туалета на третий этаж

В нижней стене туалета добавлен обычный проход с порогом, открытой створкой и небольшим участком ковра из зала. Он ведёт в карточный салон на третьем этаже. Обратная дверь WC находится в верхней стене салона. Переход происходит при обычной ходьбе или клике на дверь, отдельная клавиша взаимодействия не нужна. Точки появления удалены от порога, поэтому удержание клавиши не вызывает обратный переход. Окно на крышу и закрытая кабинка НПС сохранены.

Проверены полный путь с улицы через лестницу и крышу, ходьба и клики в обе стороны на 1440x1000 и 390x844, удержание W/S, чат, баланс, окно на крышу и отсутствие ошибок JavaScript. Пройдены TypeScript, семь серверных проверок туалета и три проверки пассивной охраны. Шесть старых тестов кошки зависят от отсутствующих игровых столов; те же шесть ошибок подтверждены на базовом коде. Игры не возвращались. Это локальная доработка, на боевой сервер она пока не устанавливалась. Проверялся режим разработки с настоящим backend, физический телефон не подключался.
