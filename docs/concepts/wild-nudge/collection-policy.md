# Star Spin: свободный выбор героини

Кандидат версии 1.6.0, 4 ноября 2026. По запросу пользователя все четыре героини доступны сразу. На экране остаются изображения, имена, принадлежность к стороне и кнопки выбора. Задания, жетоны, стоимость и открытие персонажей убраны из пользовательского интерфейса.

Общий backend при загрузке профиля бесплатно добавляет всех отсутствующих героинь из STAR_CHARACTERS. Существующие записи владения, прежние расходы жетонов, выполненные задания и UUID не переписываются. Выбор каждой стороны сохраняется. Для старых аккаунтов добавление владения повышает ревизию один раз; повторные загрузки ничего не начисляют и не меняют ревизию. Новые аккаунты сразу получают полный набор. Каталог остаётся расширяемым через общие определения героинь.

API возвращает пустой список заданий. Новые запросы answer отклоняются с кодом collection-paused и HTTP 410. Уже подтверждённые UUID проверяются раньше этого ограничения и возвращают актуальный профиль без повторной награды. Прежний запрос unlock становится бесплатным идемпотентным действием: все героини уже принадлежат аккаунту. Исторический баланс жетонов хранится для совместимости, но не показывается игроку.

Компонент star-spin-collection зарегистрирован в rtp-policy.json как genuinely nonWagered. Он не использует ставки, RNG, кошелёк, выплаты или оплаченный бонусный прогресс. Свободный выбор не меняет квалифицированные правила 2 и progress 1 игры studio-wild-nudge, все девять общих номиналов и точность расчёта полного раунда. Принятые исторические раунды правил 1 сохраняются. Полные одинаковые раунды, включая бонусные продолжения, воспроизводятся для каждой героини на всех допустимых текущих и исторических ставках.

Смена героини блокируется в клиенте до завершения вращения или принятого бонуса. Выбор меняет только оформление и сопровождающую анимацию. У пользователя остаются Светлая и Тёмная стороны с независимым сохранённым выбором. Запросы используют общую cookie-сессию, заголовок владельца, проверку origin и исходный UUID при восстановлении потерянного ответа. Смена аккаунта отменяет ожидание и отбрасывает ответ прежнего владельца.

Схема PostgreSQL star-spin-cosmetic-collection-v1 сохраняется; очистка таблиц, сброс профилей и финансовые миграции не нужны. Новый совместимый backend должен быть установлен до переключения независимого пакета 1.6.0. Версии host API/rules/progress остаются 1/2/1. Доработка не расширяет игровой каталог и не открывает новые платные режимы. Факт публикации и проверки записывается отдельно в deployment/SERVER.md.
