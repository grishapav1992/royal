# Ревью общих исходников для Galactic Reactor v1

Интеграционная основа обновлена через `work:sync`; после изменений других чатов выполнено повторное объединение свежего main. Конфликты разрешены с сохранением команд Temple, нового описания каскадного Temple и отдельной записи Reactor в коллекции. Физические места зала не переставлялись.

В `casinoExpansion.ts` добавлены новая идентичность, настройки, view и проверки её действий. В `demoExpansion.ts` новые start/move, резерв, восстановление и начисление выбираются по новому ID. Capability добавлена последним аргументом, включая все внутренние вызовы. Старые позиции флагов, paid costs, sampler, математические формулы и продолжения остальных игр не менялись. Старый клиент не получает неподдерживаемый сеанс Reactor.

HTTP-маршруты передают `X-Royal-Wild-Nudge: 1`. В нативном Nile добавлено необязательное поле `wildNudgeRules` со значениями 0/1. Авторизация, общий баланс, транзакция, журнал операций и повторы сохранены. ExpansionClient дополнительно проверяет каноническое новое сохранение и соответствие ответа UUID, ставке, сеансу и ревизии.

Общие исходники входят в хеши нескольких профилей. Штатной командой `qualify:rtp --write-proof` заново сформированы доказательства Forest Heart, Caribbean, Flag Battle, Jackie и обеих версий Temple. После проверки изолированных ветвей обновлены три проверяемых source anchor Caribbean; четыре собственных математических anchor сохранены. Двадцать два математических, транспортных, wallet и native regression-теста Caribbean прошли. Числовые правила старых игр не перенастраивались. Legacy baseline не расширялся.

Доказательство Reactor сопоставляет настоящий сервер с независимым oracle на всех ставках и полном бонусе. Реальный PostgreSQL проверяет повторные UUID, конкурирующие ревизии, отказ записи и откат, владельца, резерв до RNG, восстановление и единственное итоговое начисление. Отдельный native-тест проверяет финансовый runtime и журнал. Gate подтверждает 19 действующих квалификаций; 114 legacy-записей не выдаются за квалифицированные.

GameViewport распознаёт `.gn` как самостоятельно адаптирующуюся игру. Корень получает доступную высоту; остальные игры используют прежние ветви. Host проверяется с чатом, включая низкие и узкие экраны. Стартовое поле не показывает оплаченную линию, пропуск убирает остаточную подсветку заряда, Escape закрывает внутреннюю панель, сохраняя внешнее окно.

Проверка аудио охватывает загрузку, настройки, число событий, отмену и оценку синхронизации. Она не подтверждает качество прослушивания или физическую задержку. В headless Chrome другая вкладка не создавала visibilitychange; сценарий паузы явно использует управляемые события видимости и настоящий уже принятый серверный запрос. Реальное переключение вкладок и физический звук требуют ручного просмотра.
