# Руководство по пошаговому созданию и интеграции персонажей для слотов

Данный документ описывает единый стандарт (метрики, структуру спрайтов, триггеры и фасадное подключение) для добавления новых анимированных персонажей в движок слотов.

---

## 1. Стандартные метрики персонажа (`CharacterSlotMetrics`)
Все персонажи рендерятся в едином контейнере интерфейса слота и обязаны соответствовать единой сетке во избежание визуальных прыжков при переключении игр:

- `spriteWidth`: **128px** (базовая ширина кадра)
- `spriteHeight`: **128px** (базовая высота кадра)
- `anchorX`: **0.5** (центр по горизонтали)
- `anchorY`: **1.0** (опора по нижнему краю для корректного приземления анимации прыжков и дыхания)
- `scale`: **1.0** (базовый масштаб, допускается вариация от `0.95` до `1.05` под стилистику)
- `containerOffsetX`: **0** (смещение контейнера по X относительно панели слотов)
- `containerOffsetY`: **0** (смещение контейнера по Y)

---

## 2. Стандартные триггеры анимации (`AnimationTrigger`)
Каждый профиль персонажа обязан реализовывать следующий набор триггеров:
1. `idle` — фоновое состояние ожидания (плавное дыхание / покачивание).
2. `spin` — реакция на запуск вращения барабанов.
3. `win` — стандартная победа (выигрыш на линии).
4. `big_win` — крупный выигрыш (усиленная анимация).
5. `bonus` — выпадение бонусных символов / Scatter.
6. `jackpot` — срыв джекпота (максимально динамичная анимация).
7. `lose` — проигрыш / отсутствие выигрыша (сочувственная поза).

---

## 3. Пошаговый процесс создания нового персонажа

### Шаг 1. Подготовка спрайт-листа
1. Создайте спрайт-лист размером, кратным 128px (например, сетка кадров 128x128).
2. Расположите кадры по строкам согласно триггерам:
   - Строка 0: `idle` (кадры 0-1)
   - Строка 1: `spin` (кадры 2-3)
   - Строка 2: `win` (кадры 4-5)
   - Строка 3: Специфические кадры персонажа.

### Шаг 2. Определение профиля в `SlotCharacterAnimationFacade`
Добавьте новый профиль в `src/game/characterAnimationFacade.ts`, используя стандартные метрики и настроив длительность (`durationMs`), плавность (`interpolation`) и звуковые метки (`soundCue`):

```typescript
this.registerProfile({
  gameId: 'your_new_game',
  characterName: 'Hero Name',
  metrics: {
    spriteWidth: 128,
    spriteHeight: 128,
    anchorX: 0.5,
    anchorY: 1.0,
    scale: 1.0,
    containerOffsetX: 0,
    containerOffsetY: 0,
  },
  steps: {
    idle: [
      { frame: 0, durationMs: 250, scaleX: 1.0, scaleY: 1.0, interpolation: 'easeInOut' },
      { frame: 1, durationMs: 250, scaleX: 1.01, scaleY: 0.99, interpolation: 'easeInOut' },
    ],
    // ... остальные триггеры
  }
});
```

### Шаг 3. Интеграция в игровой интерфейс слота
В компоненте отображения слота (например, `StudioSlotUI.ts` или аналогичном) получите последовательность шагов через фасад:

```typescript
import { slotCharacterAnimationFacade } from '../game/characterAnimationFacade';

// При инициализации или смене игры
const profile = slotCharacterAnimationFacade.getProfile(gameId);

// При срабатывании триггера (например, win)
const steps = slotCharacterAnimationFacade.getSteps(gameId, 'win');
// Проигрывание кадров и применение интерполяции (scaleX, scaleY, offsetY, opacity)
```
