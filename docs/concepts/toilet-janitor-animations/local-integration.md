# Локальная интеграция Жоры

Жора стоит у правой части туалета, в точке (650, 480). Положение подошв и прямоугольник столкновения общие для клиента и сервера. Плащ не расширяет препятствие. Обход сверху, снизу и по бокам, доступ к двум свободным кабинкам, раковинам, окну и выходу на третий этаж сохранены.

Используется утверждённый прозрачный атлас без изменения рисунков. Масштаб 0.28, координаты каждого кадра и привязки подошв берутся из animations-v1.json. Персонаж остаётся на месте: моргает, смотрит в стороны, подзывает игрока, показывает товар и закрывает плащ. Подход и нажатие на него запускают реакцию. Рядом E и пробел позволяют обратиться повторно. Между автоматическими показами есть пауза. Нажатие останавливает путь игрока возле персонажа.

При уменьшенном движении ожидание неподвижно, а показ товара использует статичный раскрытый плащ. Доступны короткие реплики на русском и английском. Показ товара декоративный, покупок и изменения кошелька нет. Новый персонаж виден на миникарте, счётчик туалета показывает двух НПС. Существующий посетитель кабинки сохранён.

Проверка выполнена в локальном host с подключённым чатом: Chrome 1440x1000 и мобильная эмуляция 390x844 с касаниями. Оба браузерных сценария прошли. Они проверяют полный путь с улицы через лестницу и крышу, подход к Жоре, раскрытие плаща, обход, обе пустые кабинки, столкновение при беге, уменьшенное движение, обращение по E, выход на третий этаж и обратно, возврат через окно на крышу, отсутствие ошибок страницы и неизменность отображаемого баланса. Физические мобильные устройства не проверялись.

Серверные проверки туалета: 9 успешно. TypeScript и проверка пробелов прошли. [Хеши проверенных файлов](local-verification.json), [вид на компьютере](local-desktop.png), [мобильный вид](local-mobile.png).

Локальная игра: http://127.0.0.1:5191/. Backend перезапущен с той же временной базой, без её пересоздания. Производственная публикация не выполнялась. Исходники сохраняются в ветке feature/toilet-janitor-animation.
