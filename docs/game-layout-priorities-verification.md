# Проверка общей оболочки и пиратской игры

1 ноября 2026 года. Первый этап [плана приоритетов](game-layout-priorities-plan.md): общая оболочка и Caribbean Treasures 1.7.0. Изменения подготовлены в исходниках; производственная публикация в этот этап не входит.

## Поведение

- В компактном окне чат закрыт и доступен по кнопке со счетчиком непрочитанных сообщений. Открытая панель перекрывает игру без ее перемонтирования. Сообщения, черновик и соединение сохраняются; клавиатурный фокус остается в панели и возвращается к кнопке при закрытии.
- В просторном окне чат виден сбоку. Ручное сворачивание сохраняется при переходе между размерами. Автоматическое сворачивание на телефоне не меняет это предпочтение.
- Политика оболочки использует полезную ширину и высоту после вычитания безопасных отступов. Начальный бюджет бокового чата: ширина от 1080 и высота от 600 CSS px. На меньшей области используется панель поверх игры. Это проверяемые проектные бюджеты для первого этапа.
- Общие настройки перенесены в верхнюю панель, повторный выход и нижняя служебная полоса убраны из окна собственных игр. Метка демо-кошелька сохранена компактно рядом с названием. Подсказки управления аркад не удаляются.
- В пиратской игре вертикальная компоновка отдает полю доступную ширину и располагает консоль снизу. Короткая горизонтальная компоновка располагает поле слева и консоль справа. Большие повторные вывески сворачиваются; портрет, фон, рамка, символы и кнопка вращения сохраняют тему игры.
- Линии, общая ставка, показ линий, покупка бонуса и количество автовращений доступны в компактной панели. Используются те же элементы управления с прежними обработчиками. Полная стоимость действия и результат остаются видимыми в консоли.
- На узком телефоне поля панели настроек расположены в одну колонку, чтобы выбранная ставка помещалась целиком. Содержимое этой панели прокручивается отдельно от игры.
- Во время выбора бонусной тактики неактивные вращение и настройки освобождают место вариантам выбора. Работающая кнопка остановки автоигры сохраняется. Поворот не создает новый раунд, повторную ставку или повторное празднование результата.
- Escape закрывает внутреннюю панель перед окном игры, включая нативное событие `cancel` в WebKit. Фокус возвращается к фактической кнопке открытия, в том числе после перехода из настроек к подтверждению покупки.

## Проверенные сценарии

| Проверка | Результат |
| --- | --- |
| Chrome, 8 браузерных сценариев | Чат и непрочитанные сообщения по настоящему WebSocket; черновик; имитация уменьшения области при клавиатуре; предпочтение ПК; геометрия; параметры; бонусная покупка без подтверждения; поворот принятой операции; бонусные продолжения; Stop; прежние проверки стабильности кадра, инструментов и восстановления потерянного ответа |
| Windows WebKit, 4 сценария интерфейса | Чат, геометрия обеих ориентаций, настройки и Escape, принятый раунд и бонус, Stop после поворота |
| Кошелек и транспорт, 10 тестов | Совместимость клиентов, принятые параметры и цены, ограничения действий, конкурентные UUID, восстановление и однократное списание/начисление |
| Независимые модули, 7 тестов | Каталог, контракты, допустимые пути и манифесты, все собранные ресурсы и их SHA-256, границы загрузчика |
| Полная сборка | TypeScript, обязательная проверка RTP, 124 пакета, клиент, backend, reconciliation и payments |

Основная геометрическая матрица: 320×568, 568×320, 360×640, 640×360, 393×852, 852×393, 430×932, 932×430, 768×1024, 1024×768, 1280×720 и 1440×900 CSS px. Проверка прежнего обрамления добавляет промежуточные размеры от 342×700 и 640×480 до 1440×1000. Последовательные изменения выполняются в одном открытом экземпляре игры. Для бонусного выбора дополнительно проверены 320×568, 568×320 и 1280×720.

Проверки ищут переполнение и перекрытие основных действий, обрезанную рамку, нарушение пропорций поля и малые сенсорные области. Начальная инженерная цель основных кнопок: 44×44 CSS px; минимальная ширина клетки в этой матрице: 32 CSS px. Визуально проверены снимки вертикального и горизонтального телефона и ПК. Эти цели не являются исследовательскими порогами удобства.

Windows WebKit на стенде не предоставил игровому модулю аудиоконтекст. Его сценарии проверяют интерфейс без ожидания готовности аудио. Физический iPhone 15 Pro, Android и планшет не подключались; результаты эмуляции не являются проверкой Safari и звука на реальном устройстве. В Chrome проверена готовность аудиоресурсов; субъективное прослушивание не проводилось.

Итоговые снимки Chrome: [вертикальный экран 393×852](game-layout/phone-portrait.png) и [горизонтальный экран 852×393](game-layout/phone-landscape.png). После объединения с текущим main сохранены его компактная шапка, точный формат сумм и исправление восстановления исторических ставок.

Внутренние компоновки остальных игр не переведены на новую политику этим этапом. Каталоги, правила, ставки, вероятности, выплаты, транспорт и серверные расчеты не изменялись. Пакет сохраняет контракты host/rules/progress 1/2/1.

## Воспроизведение

Из чистой синхронизированной рабочей ветки установить зависимости и выполнить `npm run build`. Обязательный RTP-гейт проверяет 35 игровых профилей и 18 профилей общих ставок. Историческая baseline-группа сохраняет прежний статус.

Локальный стенд использует отдельную временную PostgreSQL и синтетические аккаунты:

```powershell
$env:CARIBBEAN_ARTIFACTS_DIR = 'artifacts/work/game-layout-priorities'
$env:CARIBBEAN_API_PORT = '2794'
$env:CARIBBEAN_WEB_PORT = '5394'
node --import tsx scripts/caribbean-preview.ts
```

В другом терминале с теми же тремя переменными:

```powershell
npx playwright test --config playwright.caribbean.config.ts --grep 'priority|responsive framing|spin keeps the portrait|header controls paint|an accepted start survives'
```

Для интерфейса WebKit установить его штатным `npx playwright install webkit`, задать `$env:CARIBBEAN_BROWSER = 'webkit'` и запустить тот же конфиг с `--grep 'priority'`. Для возврата к Chrome удалить эту переменную.

Проверки модулей и кошелька:

```powershell
node --import tsx --test server-tests/independent-modules.test.ts
node --import tsx scripts/database-test.ts --import tsx --test --test-concurrency=1 server-tests/caribbean-wallet.test.ts server-tests/caribbean-transport.test.ts
```

`scripts/caribbean-preview.ts` перед запуском проверяет оба порта, чтобы не принять чужой локальный сервер за собственный backend. Остановка через POST `/__test/caribbean/stop` завершает принадлежащие стенду процессы и удаляет его временную базу. После проверки удаляются промежуточные снимки и результаты, сохраняются только итоговые изображения и компактный отчет.

`.gitattributes` фиксирует LF для JSON математической квалификации: ссылки внутри доказательств зависят от точных байтов файлов. Содержимое доказательств совпадает с Git; вероятности, доказательства и их сохраненные SHA-256 не редактировались.
