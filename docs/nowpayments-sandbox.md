# NOWPayments Sandbox для первого этажа

Тестовый путь: «Мой кошелёк», раздел NOWPayments Sandbox, сумма и сценарий платежа. NOWPayments воспроизводит выбранный сценарий без перевода криптовалюты. После серверного подтверждения средства зачисляются в существующий виртуальный кошелёк, которым пользуются все 12 Royal. Игры, математика, ставки, сохранённые партии и общий чат используют прежний host.

## Изоляция

- Endpoint провайдера фиксирован: `https://api-sandbox.nowpayments.io/v1/`. Боевого fallback нет.
- Отдельные ключи: `NOWPAYMENTS_SANDBOX_API_KEY`, `NOWPAYMENTS_SANDBOX_IPN_SECRET`. Боевые настройки не используются и не заменяются.
- Отдельная таблица `nowpayments_sandbox_deposits` содержит только тестовые платёжные операции. Новый баланс или игровой микросервис не создаётся.
- Зачисление меняет только `demo_wallets` и его существующий журнал. Денежные `crypto_wallets`, платёжный outbox, Nile и вывод не используются. Старый запрет `NOWPAYMENTS_SANDBOX=true` для денежного кошелька сохранён.
- Создание платежа не зачисляет деньги. Подписанный IPN запускает независимый GET платежа с тестовым API Key. Проверяются ID, заказ, цена, валюта и оплаченная сумма. Ручная проверка работает без IPN.
- `waiting`, `confirming`, `confirmed`, `sending`, `failed`, `expired`, `refunded` не зачисляют новые средства. При ненулевом `actually_paid` статусы `finished` и `partially_paid` зачисляют подтверждённую долю, не больше цены заказа. Настоящий Sandbox 26 октября 2026 вернул `finished` с `actually_paid=0`: для этого завершённого имитированного платежа зачисляется проверенная цена заказа в виртуальных единицах. До этого обязательно отдельно проверить ID, заказ, валюту, цену, положительный `pay_amount` и статус через авторизованный GET. Нулевая частичная оплата не зачисляется. Это правило существует только в отдельном Sandbox Store и не применяется к реальным средствам. Расчёт целочисленный, с точностью игрового кошелька 0,01; субцентовый остаток не зачисляется. Один тестовый USDT соответствует одному условному доллару цены.
- Повторы и параллельные уведомления зачисляют только разницу до ранее подтверждённой суммы. Новый запрос с изменёнными параметрами под прежним ID отклоняется. При неизвестном результате создания платеж автоматически заново не создаётся.

## Подключение

1. Войти или создать отдельный кабинет на [account-sandbox.nowpayments.io](https://account-sandbox.nowpayments.io). Настроить тестовый outcome wallet, создать API Key и IPN Secret. Реальную криптовалюту не отправлять.
2. Запустить `scripts/connect-nowpayments-sandbox.command`. Ввести два тестовых ключа в скрытые поля терминала. Сначала скопировать верхний `Your API key`, вставить и нажать Enter, затем скопировать IPN Secret из `Instant payment notifications` и вставить во второе поле. Каждый ключ проверяется отдельно: пустой, слишком короткий или содержащий посторонние символы ввод запрашивается повторно. Пробелы по краям, включая неразрывные, удаляются; пробелы внутри ключа не удаляются и отклоняются. Проверка формата не подтверждает доступ к API провайдера. Скрипт создаст `.env.nowpayments-sandbox` с правами 0600 в основной рабочей папке, даже при запуске из временного worktree. Существующий файл и боевые ключи не заменяются. Секреты не передавать через чат, аргументы команд или Git.
3. При публикации сохранить этот набор отдельно от production-провайдера, передать game только тестовые переменные или соответствующие `_FILE`. Указать обычный HTTPS `PUBLIC_ORIGIN`. Включать `NOWPAYMENTS_SANDBOX_ENABLED=true` только с тестовым ключом. Обработчик уведомлений: `<PUBLIC_ORIGIN>/api/nowpayments-sandbox/ipn`.

## Проверка с официальным Sandbox 26 октября 2026

Отдельные API Key и IPN Secret проверены. Настоящее подписанное уведомление через временный Cloudflare Quick Tunnel прошло в изолированную локальную базу, вызвало подтверждение через Sandbox API и одно зачисление 1000 виртуальных единиц. Фоновый опрос в этом прогоне был отключён. По одной ставке на 10 единиц принято во всех 12 Royal через обычные HTTP-маршруты кошелька. Повтор UUID каждой ставки не дал второго списания; три повторных подтверждения платежа сохранили итоговый баланс 911.90 и единственную запись зачисления. Тестовая база удалена, туннель закрыт. Клиентский интерфейс с настоящим чатом ранее проверялся с локальным эмулятором; этот прогон с провайдером проверяет серверную цепочку.

Вспомогательные `scripts/nowpayments-sandbox-callback-check.mjs` и `scripts/nowpayments-sandbox-provider-check.ts` принимают пути к приватным ключам и отчётам через переменные окружения. Второй запускается только через `scripts/database-test.ts` на временной базе `royal_test`; `ROYAL_SANDBOX_REQUIRE_SIGNED_IPN=true` отключает опрос и требует настоящее успешное уведомление. Ключи и тела уведомлений не выводятся. Проверка сортирует и вложенные поля подписанного JSON, как основной обработчик. При `ROYAL_SANDBOX_FORWARD_LOCAL=true` приёмник пересылает только проверенные уведомления на фиксированный локальный порт 2583. Сначала требуется отдельное разрешение пользователя на временный публичный туннель.

Sandbox API иногда не отвечает в пределах тайм-аута. Не создавать замену неподтверждённому платежу: проверять сохранённую операцию. Успешный итоговый прогон и ограничения записаны в `docs/nowpayments-sandbox-verification.json`.

Официальный сценарий `partially_paid` в этой проверке тоже вернул `actually_paid=0`. Такая операция сохраняет статус частичной оплаты и зачисляет 0, без придуманной доли оплаты. Положительная частичная сумма зачисляется пропорционально подтверждённой оплате. Исключение для нулевой суммы действует только при проверенном `finished` внутри Sandbox.

На рабочем сайте Sandbox ещё не включён. Полная сверка production остановилась на тайм-ауте списка Docker-контейнеров при высокой нагрузке сервера; другой выпуск проекта разбирает ту же задержку. Перед публикацией требуется новая сверка его фактической версии и защищённый выпуск только изменений Sandbox.
4. Проверить `success`, `partially_paid`, `failed`, повторное уведомление, повторное открытие и ставку во всех 12 играх. Не считать программный эмулятор доказательством ответа настоящего Sandbox. Не включать реальные выводы для тестовых средств.

## Ограничение провайдера

В [официальной коллекции Sandbox](https://documenter.getpostman.com/view/7907941/T1LSCRHC) указано: с 2025 года окружение не поддерживается синхронно с Production и предоставляется as-is. Тест подтверждает тестовую интеграцию и работу виртуального кошелька, но не доказывает полную совместимость с актуальным боевым API. Переводы реальных средств этой задачей не разрешены и не требуются.
