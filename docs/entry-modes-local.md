# Локальные режимы Royal

Запуск: `npm ci`, затем `npm run preview:entry`. По умолчанию адрес `http://127.0.0.1:5198`, backend использует порт 2698. При запуске собираются существующие игровые модули. Порты можно задать через `ENTRY_WEB_PORT` и `ENTRY_API_PORT`.

Тестовый аккаунт: `guest@royal.local`, пароль `RoyalLocal2026`, начальный тестовый баланс 50 USDT. Стенд использует отдельную временную PostgreSQL, не загружает `.env` и отключает внешние платежи и провайдеров. Данные удаляются при штатной остановке через Ctrl+C. Дополнительным локальным тестовым аккаунтам можно один раз выдать 50 USDT через POST `/__local/entry-credit` с их авторизованной сессией. Этот маршрут существует только в локальном runner.

Сначала Royal проверяет сессию и при необходимости показывает форму входа. После входа доступны «Войти в клуб» и «Открыть казино». Запоминание выбора включается на экране выбора или в настройках игрока. Явные ссылки `/?mode=club` и `/?mode=casino` после входа открывают нужный режим напрямую. `/?offline=1` открывает одиночный осмотр клуба.

Казино использует тот же каталог Royal, загрузчик независимых игр, авторизацию, кошелёк и чат комнаты. Новые игры и внешние коллекции не включаются. При первом входе нового игрока через казино сохраняется стандартный персонаж; редактор остаётся в настройках.

Сцена клуба загружается при первом выборе клуба. Переключение в пределах страницы сохраняет сетевую сессию, сообщения и черновик чата. Созданная сцена при переходе в казино приостанавливается. Выбор режима сам по себе не создаёт ставку и не занимает автомат.

Проверка работающего стенда: `npx playwright test --config playwright.entry.config.ts`. Сценарии проверяют выбор и сохранение режима, первый вход, общий чат между двумя режимами, сохранение сетевой сессии, телефон в двух ориентациях и восстановление потерянного ответа ставки с тем же UUID. Проверка запускается только против локального стенда с тестовым кредитом.

Ограничение первой версии: присутствие и чат остаются привязаны к существующей комнате клуба. Отдельный глобальный чат всех комнат и отдельная модель присутствия для каталога здесь не вводятся.
