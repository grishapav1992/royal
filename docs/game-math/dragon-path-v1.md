# Серверные правила «Пути дракона», версия 1

**Сервер, общий виртуальный кошелёк и клиент связаны в исходниках.** Локальная квалификация игры прошла. Ни штатная сборка Royal, ни сборка отдельного пакета не прошли общий контроль: нуждаются в обновлении доказательства других игр, использующих те же исходники. Новый пакет не развёрнут.

## Поле и выплаты

- Поле 5×5. Десять фиксированных линий совпадают с линиями визуала. Ставка от 0.10 до 50.00 с шагом 0.01 покрывает весь раунд, а не одну линию.
- На каждой линии оплачивается лучшая комбинация из трёх, четырёх или пяти символов подряд слева. Мастер-панда заменяет обычный символ, но не свиток; у последовательности из одних панд есть своя выплата.
- Вертикаль из пяти одинаковых обычных символов платит как совпадение пяти таких символов. Подстановки по вертикали нет. Линейная и вертикальная выплаты складываются при пересечении.
- Символы всех клеток выбираются независимо с весами 2, 3, 4, 5, 8, 9, 10, 11, 12 от свитка до змеи. Обычное и бесплатное вращение используют одинаковое распределение. Коэффициенты заданы в сотых долях полной ставки.

## Раунд, кошелёк и восстановление

Три свитка или больше открывают одно бесплатное вращение с множителем ×3 на выигрыш этого вращения. Свитки в бесплатном вращении не добавляют ходов. В конце выбирают Персик Мудрости или Пельмени Мастера; этот выбор сохраняется в снимке, не меняет выплату и не добавляет предмет в постоянную коллекцию.

`DemoExpansionStore` принимает одну виртуальную ставку. Без бонуса раунд завершается в ревизии 1. При бонусе ревизия 1 хранит обычное поле, ревизия 2 добавляет бесплатное, а ревизия 3 фиксирует выбор и закрывает раунд. Недоступные действия и чужую сессию сервер отвергает. Принятые действия возвращаются по прежнему UUID без нового броска. Новый заголовок совместимости применяется только виртуальным маршрутом; клиенты без него не видят снимки игры. Платёжный контур не принимает эту игру.

`expansionExactAward` берёт точную рациональную сумму из сохранённого раунда. Общий расчёт целых центов применяется один раз после завершения. Дроби не отбрасываются по отдельным линиям и этапам. Виртуальный журнал хранит одно начальное списание и одну итоговую запись. Адаптер на клиенте не рассчитывает исход и не начисляет баланс.

## Проверки

**Теоретический RTP полного раунда: 96,05517035%. Вероятность бонуса: 4,20402238%.** Это точное математическое ожидание, не результат симуляции и не обещание игроку. Независимый перебор всех 59 049 комбинаций одной линии проверяет оценщик. Ожидания линий и вертикалей складываются, бонусное ожидание определяется биномиальной вероятностью трёх или более свитков.

[Локальная квалификация игры](qualifications/shared-stakes-panda-dragon-preview.json) покрывает 2 304 воспроизведения раунда, все 4 991 суммы для каждого выбора и 34 сценария общего виртуального кошелька с двумя бесплатными действиями. Отдельный HTTP-тест использует общий клиент и проверяет потерю ответа после записи раунда, восстановление с тем же UUID, отсутствие лишней проводки, оба выбора и отказ старому клиенту. Изолированная проверка денежного маршрута подтверждает отказ без изменения баланса.

```bash
node --import tsx scripts/database-test.ts --import tsx --test server-tests/dragon-path-rules.test.ts server-tests/dragon-path-wallet.test.ts
```

## Граница допуска

Сценарного сервиса в исходниках игры больше нет. Запись о бесплатном режиме удалена; профиль использует [штатную политику ставок](../game-stakes.md), не исключение из контроля. Для допуска нужно зафиксировать точные исходники кандидата в Git, сформировать проверенную проекцию того и другого исполнения и повторить проверку ранее принятых раундов. Также нужно заново получить 29 затронутых существующих файлов доказательств. Их прежние отпечатки сохранены. Без этого обычная сборка и отдельная сборка модуля останавливаются; настольный и мобильный браузерные сценарии виртуальной версии не выполнены.
