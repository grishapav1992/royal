# Nitro Run: Стартовая прямая

Заменяет оформление [Night Circuit](../nitro-redesign/README.md). Пакет `@royal/nitro-run` 1.3.0, совместимость host/rules/progress 1/2/1 не изменилась. Утверждённый макет: [Nitro Run: редизайн](https://claude.ai/artifact/8BfJGAggfSMM3FEf2o5aCd).

Изменено только представление: разметка `NitroRunUI`, расчёт `NitroRunLayout`, стили `nitro-run.css` и `nitro-run-layout.css`. Математика, правила, ставки, кошелёк, протокол, символы и фон не менялись.

## Визуальное направление

Ночная стартовая прямая: чёрный асфальт, сигнальный жёлтый старт, зелёный выигрыш, фиолетовое нитро. Шахматная полоса финишного флага проходит по верху поля и под логотипом. Передача показана цифрой и пятью шифт-лампами ×1…×5: две зелёные, две жёлтые, одна красная. Цвет только подкрепляет цифру.

| Роль | Цвет |
| --- | --- |
| Фон | `#0A0A0C` |
| Поверхность карточек | `#141418` |
| Линии | `#2C2C35`, `#3A3A45` |
| Основной текст | `#F4F1EA` |
| Вторичный текст | `#A9A6B3` |
| Старт, логотип, флаги | `#FFD400` |
| Выигрыш, передачи ×1–×2 | `#33E07A` |
| Нитро, бонусная гонка | `#8B7BFF` |
| Передача ×5, ошибка | `#FF4D3D` |

Шрифты: Exo 2 Italic 800/900 для логотипа, сумм и передачи; Manrope 500–800 для остального текста. Минимальный размер текста 12 px.

## Компоновка

`NitroRunLayout` выбирает профиль по фактическому размеру корня модуля после размещения чата.

| Профиль | Условие | Композиция |
| --- | --- | --- |
| Широкий | ширина от 780 px, высота от 560 px | Поле и строка статуса слева. Справа одна колонка: логотип, передача, нитро, флаги, пульт. |
| Портретный | остальные размеры | Логотип, полоса из трёх приборов, поле, строка статуса, свободное место, пульт внизу. |
| Горизонтальный | ширина больше высоты, высота меньше 560 px | Приборы, поле, статус и пульт тремя колонками. |

В широком профиле низкая колонка сокращает подсказки, затем объединяет цифру передачи с лампами. При высоте портретного корня меньше 570 px логотип скрывается. В горизонтальном корне ниже 300 px выигрыш раунда переходит над приборами, а пульт занимает всю правую колонку.

Ошибка, восстановление и подсказка кошелька показываются поверх строки статуса. Размер поля при этом не меняется. Во время бесплатной гонки рамка поля и заголовок становятся фиолетовыми, «Пауза серии» занимает место «Авто». Цена хода остаётся видимой внутри блока ставки.

На экране 1440×900 с чатом рамка поля 792×662 px (было 774×647 px). [Измерения восьми размеров](layout.json).

## Проверка

```bash
npm --prefix games/nitro-run run build
node node_modules/typescript/bin/tsc --noEmit
npm run check:rtp
LAYOUT_API_PORT=2979 LAYOUT_WEB_PORT=5479 LAYOUT_ARTIFACTS_DIR=artifacts/work/nitro-run-start-line LAYOUT_TASK_ID=nitro-run-start-line LAYOUT_SCENARIOS=1 node --import tsx scripts/game-layout-preview.ts
```

В другом терминале с теми же переменными:

```bash
npx playwright test --config playwright.nitro.config.ts
```

Результат для пакета `1.3.0-080468c6d008`: сборка с RTP gate, полный TypeScript и `check:rtp` прошли. Все 5 сценариев Chromium в подключённом host прошли: поле без прокрутки на восьми размерах, устойчивость поля при вращении, восстановлении и заряде нитро, открытие и закрытие мобильного чата, панель автоигры без ставки, одна принятая ставка 0,10 USDT и «Стоп», естественная бонусная гонка в обеих ориентациях. Тест компоновки обновлён под новую схему: колонка приборов справа от поля, строка статуса под полем.

Сценарий `independent-game-modules.spec.ts` для Nitro Run не запускался до конца: он открывает Saffron Spin, а сборка этого модуля на текущем `origin/main` падает из-за отсутствующей обложки `games/wild-nudge/assets/catalog-cover.webp`. Физические устройства и приятность звука не проверялись.
