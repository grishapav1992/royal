# Затопленный храм: макет «Отлив»

25 ноября 2026 года. Пользователь принял концепцию словами и попросил макет. Это макет: пакет игры, сервер, математика v2, ставки и правила не менялись.

26 ноября 2026 года «Отлив» опубликован в Royal в пакете `0.11.0-77ebc531cf0a`. [Проверки выпуска](../../../deployment/releases/flooded-temple-ebb-20261126-v1/verification.json)

Вода показывает подтверждённый множитель: ×1, ×2, ×3, ×5 в храме и ×3, ×6, ×9, ×15 в святилище. Раунды настоящие, получены функциями `advanceCascade` и `cascadeUnits`; сиды для кнопок просмотра ищет `find.ts`.

Героиня: эскиз и четырнадцать поз через A6API (gpt-image-2, images/edits по эскизу). Покой и мелкие жесты сделаны из эскиза на шарнирах, действия из поз. Выравнивание и правки в `bake-poses.mjs`: в замахе убрана лишняя третья нога, в приземлении лишняя вторая коса. Прыжок, реликвия и карта получены повторными запросами 26.11: в первый раз провайдер ответил ссылками на посторонние адреса вместо картинок.

Фон, символы, сундук, рычаг, каменная рамка и звуки взяты из текущей игры. Маски воды, водопадов и огня строит `bake.mjs`.

Сборка: `node bake.mjs <папка> <эскиз.png>`, `node bake-poses.mjs <папка поз> <папка>`, затем `./build.sh <папка>`.
