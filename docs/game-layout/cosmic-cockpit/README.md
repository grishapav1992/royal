# Cosmic Escape: кабина

Развивает утверждённый [редизайн ноября 2026 года](../cosmic-redesign/BRIEF.md). Пакет `@royal/cosmic-escape` 1.2.0, совместимость host/rules/progress 1/2/1 не изменилась. Утверждённый макет: [Cosmic: редизайн](https://claude.ai/artifact/AaL4DLxcemAPBGNcpm2yJq#page-space), страница «Редизайн в текущем стиле».

Изменено только представление. Математика, ставки, кошелёк, протокол, звук, символы, фон, гонщица и её анимации прежние. Стиль сохранён: Unbounded и Manrope, тёмно-фиолетовые поверхности, янтарный для основной игры, бирюзовый для миссии, латунная рамка.

Интерфейс перенесён из `src/ui/` в `games/cosmic-escape/`, как у Caramel Carnival, Nitro RUN и GIRLHUB. Host эти файлы не импортирует. Общий `src/ui/cosmic-escape.css` остаётся на месте: его использует Velvet Reign. Новые английские подписи лежат в `cosmicText.ts` и приходят вместе с пакетом.

## Что изменено

| Элемент | Решение |
| --- | --- |
| Поле | Пять цельных барабанов в латунной рамке с двумя световыми полосами. Логотип над полем убран, имя игры остаётся в шапке окна. |
| Энергия | Вертикальная шкала рядом с полем. Точный множитель написан над шкалой, ступени ×1, ×2, ×4, ×6, ×10, ×15, ×20, ×30, ×40, ×50 показывают масштаб. |
| Результат | Одна строка под полем: подсказка, сумма, линия, пояснение, ошибка и восстановление. |
| Кнопка | Реактор по центру панели. В миссии число сегментов равно числу вращений (10, 12 или 15), горят сыгранные вместе с текущим. В автоигре сегменты показывают остаток. Во время обычного вращения свет идёт по кольцу. |
| Миссии | Три карточки с полной ценой на кнопке. Нажатие на цену покупает миссию, отдельного выбора нет. |
| Пауза серии | Занимает место «Авто», размер и положение совпадают. |

Частичный возврат меньше ставки подписан «Возврат части ставки» и показан без выигрышного цвета. В миссии строка называет сумму текущего вращения и итог миссии, который зачисляется в конце.

## Постоянная геометрия

Размер поля считается из площади, которую host отдаёт игре: `.cx-scene` служит контейнером, `.cx-deck` получает точные ширину и высоту поля. Строка результата, шкала, ячейки баланса и выигрыша, ставка, «Авто» и реактор имеют фиксированные размеры. Текст внутри обрезается и не переносит соседей. Длинные суммы уменьшаются внутри своей ячейки.

`tests/game-layout-slots.spec.ts` проверяет это двумя способами: на каждом кадре настоящих раундов (проигрыш, выигрыш, крупный выигрыш, миссия, пауза) сверяется положение поля, строки, шкалы, панели, кнопок; затем во все изменяемые подписи подставляется слишком длинный текст и крупные суммы.

## Компоновка

| Профиль | Композиция |
| --- | --- |
| Широкий | Гонщица, поле, шкала энергии, порталы и миссии. Под полем строка результата, внизу панель с реактором по центру. |
| Портретный | Полоса гонщицы с порталами, энергией и миссиями, поле во всю ширину, строка результата, панель. В коротких окнах гонщица скрыта, счётчики стоят одной строкой. |
| Горизонтальный | Поле и строка счётчиков слева, панель справа. Ошибка занимает всю строку. |
