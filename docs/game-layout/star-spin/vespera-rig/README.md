# Дарт Веспера: детали для 2D-рига

Персонаж сверен с открытым интерфейсом Star Spin 17 ноября 2026 года. Исходник: `games/wild-nudge/assets/characters/vespera.png`, 1024 x 1536 px, SHA-256 `5c1c8eedc4616fea4215c09303c81830318233aab7dea47efd8eec024a63d8e4`.

## Основной набор

В `parts/` находятся **19 отдельных PNG с прозрачным фоном**. Это реконструированные текстуры по исходному персонажу: закрытые поверхности дополнены, плащ и оружие восстановлены целиком. Использован встроенный image_gen, затем выполнены техническая нарезка и удаление прозрачных полей без масштабирования. Запросы сохранены в `prompts.json`, листы генерации в `sheets/`.

| Файлы | Назначение |
| --- | --- |
| `head.png` | Голова с лицом, передними волосами и шеей |
| `hair_back.png` | Отдельные длинные волосы для сеточной деформации |
| `torso.png`, `pelvis.png` | Корпус, таз и пояс, с перекрытием на талии |
| `upper_arm_r.png`, `forearm_r.png`, `hand_r.png` | Правая рука персонажа, сторона меча |
| `upper_arm_l.png`, `forearm_l.png`, `hand_l.png` | Левая рука персонажа, кисть на бедре |
| `thigh_r.png`, `shin_r.png`, `boot_r.png` | Правая нога, наколенник входит в голень |
| `thigh_l.png`, `shin_l.png`, `boot_l.png` | Левая нога, наколенник входит в голень |
| `cape_back.png` | Целый задний плащ без отверстий от корпуса и ног |
| `tabard.png` | Передняя длинная тканевая полоса |
| `saber.png` | Целый меч с рукоятью, клинком и прозрачным свечением |

`r` и `l` означают анатомические стороны персонажа. Правая рука находится слева на исходной картинке. Обзор всех деталей: `parts-overview.png`.

## Подготовка к привязке

1. Использовать `assembled-source.png` как ориентир исходной позы. Добавить задний плащ, волосы, ноги, таз, корпус, руки, переднюю ткань, оружие и голову отдельными слоями. Порядок кисти и оружия уточнить вокруг хвата.
2. Подогнать размеры деталей по ориентиру. Листы генерации не имеют общего масштаба: одинаковая ширина ячеек не означает одинаковый масштаб частей тела. Позиции исходной нарезки в JSON не являются координатами дорисованных текстур.
3. Установить суставы в плечах, локтях, запястьях, тазобедренных суставах, коленях и голеностопах. `rig-map.svg` показывает начальные ориентиры на исходной позе. Декоративным слоям хватит родительской кости и сетки.
4. Завести концы соседних деталей друг под друга. Воротник головы и корпуса, пояс корпуса и таза содержат перекрывающуюся одежду. Скрыть дублирующий контур маской при сборке.
5. Плащ, волосы и переднюю ткань деформировать сеткой с закреплённой верхней частью. Проверить стыки на предполагаемом диапазоне движений после установки костей.

Это набор растровых элементов для последующей сборки. Готового скелета, весов, Rive-файла и проверки движений в нём пока нет. Дорисовка сохраняет образ и материалы, но не является пиксельно точной копией исходного лица и каждого шва. Для сохранения исходного лица есть `source-parts/head.png`; его следует использовать вместе с исходным расположением волос или отдельно подогнать стык волос.

## Исходные пиксели и проверка

Дополнительно сохранена разметка **24 видимых областей исходного изображения**, без генеративной дорисовки:

- `source-parts/`: обрезанные по прозрачным полям области в исходном масштабе.
- `aligned/`: те же области на общем холсте 1024 x 1536 px, для импорта с сохранением взаимного положения.
- `vespera-layered.svg`: переносимый SVG с 24 именованными группами и встроенными PNG. Это растровые слои внутри SVG, а не векторизация персонажа.
- `manifest.json`: координаты, размеры, начальные точки суставов, родительские связи, SHA-256 и происхождение каждого элемента.
- `assembled-source.png`: проверенная обратная сборка исходных областей.

Эти 24 области служат ориентиром для совмещения и сохранения исходных пикселей. В них остаются видимые перекрытия одежды, обрезанные скрытые поверхности и отдельные краевые фрагменты. Они не заменяют восстановленные текстуры из `parts/` при раскрытии суставов. `cape_back` исходной разметки содержит остаточные края, а не целый восстановленный плащ.

Каждый видимый исходный пиксель назначен ровно одному слою; максимальное отличие каналов при обратной сборке равно **0**. Это проверка сохранности изображения, а не подтверждение качества будущего движения. Проверены прозрачный канал PNG, непустота деталей и отсутствие пересечения видимого контура с границами ячеек при нарезке. Генерация и нарезка не подключены к работающей игре.

Повторить экспорт из корня проекта: `node docs/game-layout/star-spin/vespera-rig/build-parts.mjs`. Требуется существующая зависимость `sharp`. Новая платная генерация при экспорте не запускается.
