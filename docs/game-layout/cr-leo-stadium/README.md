# CR vs. Leo: живой стадион

Представление игры `original-cr-vs-leo` в модуле `@royal/cr-vs-leo` 1.2.0. Совместимость host/rules/progress 1/1/1 прежняя. Утверждённый макет: [CR vs. Leo, редизайн](https://claude.ai/artifact/6pEAmyJmR3xLkZqUXBu8AY).

Стиль сохранён: дневной стадион, игроки, вратарь, стенка, мяч, логотип, палитра, шрифты и записи звука. Математика, ставки, кошелёк, протокол, сервер и время исхода удара не изменились. Второго игрока в кадре нет по решению пользователя.

Интерфейс перенесён из `src/ui/` в `games/cr-vs-leo/`. Общим остался `src/ui/crLeoSprites.ts`: его использует Jackie Chan.

## Состав

| Файл | Назначение |

| `crLeoAssets.ts`, `crLeoAssetManifest.ts` | Загрузка |

## Экран

| Элемент | Решение |
| --- | --- |
| Верх поля | Игрок и точка удара слева, сумма справа. До первого гола сумма 0,00 и выплата за первый гол. |
| Полоса серии | Пять ударов с выплатами. Забитый гол зелёный, следующий белый, промах красный. Кружков поверх поля нет. |
| Управление | Снизу во всех размерах, включая телефон боком. Боковой колонки нет. |
| Кнопки | «Забрать» и «Бить» постоянного места и размера. До гола «Забрать» неактивна. |
| Игрок | Выбирается на экране, в настройках телефона остались правила и звук. |
| Ошибка и восстановление | Плашка поверх поля, раскладку не меняет. |

Подписи не мельче 11 px. Раскладка одинакова до удара, в полёте, после гола и при смене удара.

## Карточка событий

Сцена показывает только подтверждённые удары. Ожидание ответа исход не раскрывает.

| Событие | Условие | Изображение | Звук |
| --- | --- | --- | --- |
| Покой | Нет удара | Облака, лёгкое движение вратаря и игрока | Фон стадиона |
| Смена точки | Выбран другой удар | Камера переезжает за 0,8 с и заканчивает до касания мяча | Фон |
| Удар | 1,12 с | Трава, толчок камеры, след и тень мяча, камера слегка подаётся вперёд, игрок отходит от створа | Удар |
| Гол | Время исхода | Сетка, волна по трибуне, вспышки не чаще трёх в секунду | Радость трибуны |
| Сейв, штанга, стенка, мимо | Время исхода | Приземление вратаря, дрожь штанги, отклик стенки; без праздника | Прежний звук промаха |
| Забрать | Подтверждённая выплата | Спокойный кулак 2,6 с | Без фразы |
| Пять голов | Подтверждённая выплата | Конфетти, файеры, прыжок CR или футболка Leo | Прежняя фраза, титр на приземлении |

Титр и сумма берут зачисленную выплату. Открытая заново серия показана конечным кадром без звука. Уменьшенное движение: неподвижный итог без частиц, один кадр на изменение.

Исправлено: у CR в позах последнего ряда был срезан верх головы.

## Ресурсы

`public/assets/cr-vs-leo/v3` содержит стадион без облаков, слой облаков и маску мест. Их строит `scripts/bake-cr-leo-stadium.mjs` из `v2/stadium-free.webp`; новых рисунков нет. Прежние файлы оставлены: `v2/stadium.webp` нужен обложке каталога.
