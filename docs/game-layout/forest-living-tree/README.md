# Сердце леса: «Живое дерево»

Новое оформление Forest Heart (`studio-forest-heart`). Пакет `@royal/forest-heart` 1.17.0, совместимость host/rules/progress 1/1/1 не изменилась. Утверждённый макет: [Сердце леса: Живое дерево](https://claude.ai/artifact/YKVeSjLpCPCLuRN7chapVr), исходники макета в [prototype](prototype), картинки для него создаёт `cut.mjs`. Статус: опубликовано 24 ноября 2026, пакет `1.17.0-c57c2cdca5a6`, выпуск `forest-living-tree-20261124-v1`. Эльфийка без видео: пакет `1.18.0-065d090c31df`, выпуск `forest-actions-20261124-v1`.

Изменено представление. Математика, правила, выплаты, ставки, кошелёк, протокол, восстановление хода, звуки, музыка и видеожесты эльфийки не менялись. Добавлена автоигра по общему правилу проекта.

## Стиль

Сохранены ночной лес, эльфийка с позами и видео, плитки, корни, кристалл, цветок, логотип, тёмно-зелёные панели с золотом, шрифты Georgia и Arial. Новых генераций нет. В `public/assets/forest-heart/v5` лежат вырезки из прежней графики, порядок нарезки в [cut.mjs](prototype/cut.mjs):

| `bud.webp` | бутон из выбранного эталона `approved-concept-v1.png` |
| `gem-top.webp`, `gem-bottom.webp` | самоцветы логотипа `v2/title.webp` |
| `blossom-pink.webp`, `blossom-gold.webp` | цветок логотипа, перекрашенный |

| Роль | Цвет |
| --- | --- |
| Фон и табличка | `#071511`, `#1b3b2c` к `#0c2019` |
| Золото рамок | `#c9a35a`, выигрыш `#ffe09a` |
| Главная кнопка | `#62ffd0` к `#0a3327`, в бонусе `#ffe39a` к `#3a260a` |
| Свет ×1, ×2, ×5, ×20, ×100 | `#63f5d0`, `#6fd8ff`, `#b48bff`, `#ffc94f`, `#ffe08a` |

Цвет света всегда сопровождается числом энергии. Текст не мельче 12 px, вторые строки кнопок на узких экранах 11 px.

## Компоновка

`forestGeometry` считает сцену только по размеру окна модуля. Тексты, выигрыш, бонус и ошибка поле не двигают. Рама собирается из `v2/frame.webp` зеркальной укладкой, поэтому стыков нет.

| Профиль | Условие | Композиция |
| --- | --- | --- |
| Широкий | от 900×600, ширина не меньше высоты | Логотип в арке, кристалл слева, цветы справа, эльфийка во весь рост, табличка под полем, кнопка на оси поля. |
| Портретный | остальные размеры | Эльфийка и логотип сверху, поле, табличка, ставка и кнопка снизу. Ниже 640 px высоты логотип скрыт: название показывает хост. |
| Горизонтальный | ширина больше высоты, высота меньше 600 | Поле с эльфийкой слева, табличка и пульт справа. На узких экранах эльфийка скрыта. |

## События

| Событие | Условие показа | Анимация поля | Звук |
| --- | --- | --- | --- |
| Нажатие | сразу, до ответа | 12 прямых корней крутятся, бутоны закрываются. 13 узлов и закреплённые корни неподвижны. Итога нет. | нет нового |
| Поле принято | подтверждённый ответ | Корни встают волной слева направо, на прежней схеме акцента | `land` |
| Энергия выше ×1 | подтверждённое поле | Кристалл и свет меняют цвет | прежний |
| Поток | взаимно соединённые корни | Свет идёт в порядке `rootWave`, гаснет в тупиках | `flow` |
| Цветок | свет дошёл | Бутон раскрывается, сумма летит в табличку | `flower` |
| Руна | этап choice | Корни «дышат» светом, при наведении виден поворот. Лучший ход не подсказан. | `choice` |
| Бонус | этап bonus | Лес светлеет, рама цветёт, четыре семени, золотая лоза держит корень | `bonus` |
| Выигрыш | итог больше ставки | Лепестки, рамка таблички | `win` |
| Крупный | итог от ×10 | Лучи, волна по раме, дождь лепестков в стороне от поля, сумма растёт | `big` |

Возврат меньше ставки и нулевой итог празднования не получают. Показанный баланс меняется после показа итога. «Показать итог» останавливает украшения без нового запроса. Пауза, скрытая вкладка, закрытие, смена аккаунта и уменьшенное движение останавливают таймеры, частицы и звуки. При восстановлении праздник не повторяется.

Длительности являются решениями этой игры, а не измеренными порогами восприятия.

## Эльфийка

С пакета 1.18.0 видео в игре нет. Эльфийка показывает действия и реакции на семи прежних рисунках, веки берутся из `v3/elf-blink.webp`. Новых генераций нет, файлы `video-v3` остаются в репозитории для старых пакетов.

| Событие | Действие |
| --- | --- |
| Покой | дыхание, волосы, ткань, моргание |
| Нажатие и ожидание ответа | поднимает руку, искры из ладони крутят корни, пока не придёт ответ |
| Корни встали | короткий кивок и движение руки |
| Энергия ×2 | отклик светом, ×5 и выше: поднимает кристалл. Кристалл и магия в руке берут цвет энергии |
| Свет по корням | ведёт поток рукой, искры идут к источнику |
| Первый цветок | поднимает лотос, на следующие отвечает движением. Искры цветка летят в её кристалл |
| Руна | указывает на поле, за наведённым корнем тянутся искры |
| Поворот корня | направляет луч в выбранную клетку |
| Бонус | держит кристалл двумя руками, закрепление корня отмечает искрами |
| Выигрыш, крупный | рука на сердце, взмах с золотыми искрами, пока растёт сумма |
| Частичный возврат | спокойный кивок |
| Проигрыш | опускает взгляд |

Смена рисунка проходит волной света от действующей руки. Одинаковые части не меняются, лицо движется как одно целое, на экране не больше двух рисунков. Начатая смена всегда завершается. Действие держится до следующего события, между действиями эльфийка не возвращается в покой. Уменьшенное движение показывает позы без анимации.

## Автоигра

«Авто» открывает окно с выбором 10, 25, 50 или 100 и кнопкой запуска. До запуска ставки нет. Считаются только платные поля. Бесплатные импульсы идут сами, на руне серия ждёт игрока. После бонуса окно итога: кнопка продолжает серию, крестик и Escape её завершают. «Стоп» доступен всё время. Серию останавливают скрытие окна, закрытие, смена аккаунта, нехватка средств, ошибка и открытие правил или настроек.

## Отличия от макета

- Слово «импульс» вместо «вращение», как в правилах игры.
- Ставка показана с точкой, её рисует общий элемент с ручным вводом.
- Логотип есть только на русском, как раньше. В английской версии название набрано шрифтом.
- На экранах ниже 640 px логотип скрыт.
