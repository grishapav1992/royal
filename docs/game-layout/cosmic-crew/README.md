# Cosmic Escape: экипаж

Развивает [кабину](../cosmic-cockpit/README.md). Пакет `@royal/cosmic-escape` 1.3.0, совместимость host/rules/progress 1/2/1 не изменилась. Утверждённый макет: [Cosmic: редизайн, страница «Экипаж»](https://claude.ai/artifact/AaL4DLxcemAPBGNcpm2yJq#page-crew).

Завершённые платные раунды дают очки, очки открывают персонажей. Персонаж меняет только изображение героини: математика, ставки, шансы, выплаты и кошелёк прежние.

## Правила

| Сумма, списанная за раунд, USDT | Очки |
| --- | --- |
| 0,10–0,49 | 1 |
| 0,50–0,99 | 2 |
| 1,00–4,99 | 3 |
| 5,00–9,99 | 5 |
| 10,00–49,99 | 8 |
| от 50,00 | 12 |

- Считается вся списанная сумма. Купленная миссия учитывается по полной цене. Бесплатные вращения и выигрыш очков не добавляют.
- Отменённый раунд и возврат ставки очков не дают.
- Отсчёт начинается с запуска системы, прошлые раунды не учитываются.
- Гонщица открыта сразу, серебряная героиня открывается за 100 очков. Третья и четвёртая капсулы подписаны «Скоро», порогов для игрока пока нет. Очки продолжают копиться.
- Новый персонаж ждёт нажатия и не прерывает игру. Выбор меняется между раундами.
- Имена «Гонщица» и «Серебряная героиня» рабочие.

## Сервер

`src/shared/cosmicCrew.ts` хранит шкалу, состав и проверку профиля. `server/cosmicCrew.ts` ведёт профиль, `server/cosmicCrewRoutes.ts` отдаёт `GET` и `POST /api/cosmic-crew`.

Очки считаются из `progression_outbox`: запись о платном раунде появляется там один раз, внутри транзакции расчёта. Экипаж читает её после подтверждения и запоминает учтённые раунды в `cosmic_crew_rounds`, поэтому повторный запрос ничего не добавляет. Файлы кошелька и расчёта раундов не менялись, подписи 39 профилей RTP и 21 политики ставок действительны. Начисление зависит от настройки прогресса `earn_enabled`.

Миграция `cosmic-crew-v1` создаёт таблицы `cosmic_crew_start`, `cosmic_crew_profiles`, `cosmic_crew_rounds`, `cosmic_crew_revealed` и индекс по времени записей аккаунта. Существующие данные не изменяются. В `rtp-policy.json` экипаж записан как `nonWagered`.

Сервер отказывает в выборе закрытого персонажа (403 `character-locked`) и в смене во время незавершённого раунда (409 `round-active`). Если сервис недоступен, табличка пишет «Прогресс недоступен», игра продолжает работать с гонщицей.

## Интерфейс

| Место | Решение |
| --- | --- |
| ПК | Героиня стоит на подиуме. Табличка показывает имя, число открытых, полосу и остаток до следующей. После раунда на ней появляется прибавка. |
| Узкая табличка | При открытом чате, в окне 1280 и на телефоне имя заменено словом «Экипаж», число записано как «1 из 4». |
| Короткие и горизонтальные окна | Таблички нет, в шапке окна стоит кнопка с кольцом прогресса. |
| Новый персонаж | Подиум, табличка и кольцо становятся бирюзовыми, на ПК в строке результата появляется подпись. |
| Окно «Экипаж» | Четыре капсулы, крупная фигура, шкала очков и пояснение. |
| Открытие капсулы | Створки расходятся, кнопки «Выбрать» и «В экипаж». При уменьшенном движении створки сразу открыты. |

Табличка, подиум и героиня входят в общую проверку неподвижности. Её строки имеют постоянную высоту.

## Графика

`public/assets/cosmic-guardians/silver-v1/` содержит десять анимаций и кадров серебряной героини: те же клипы, длительности и холст, что у гонщицы. Файлы из ветки `feature/cosmic-escape-silver-heroine` перекодированы с 28,6 до 18,3 МБ с теми же кадрами. Загружаются только клипы выбранного персонажа.
