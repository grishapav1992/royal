# GIRLHUB: Студия после заката

Новое оформление GIRLHUB (`studio-afterglow`). Пакет `@royal/girlhub` 1.4.0, совместимость host/rules/progress 1/2/4 не изменилась. Утверждённый макет: [GIRLHUB: редизайн](https://claude.ai/artifact/CggComqE5fY7BBWJAyrWhw).

Изменено только представление. Математика, правила, ставки, кошелёк, протокол, гардероб, звук, голосовые реакции, символы, фон и фото героинь не менялись.

## Что перенесено в модуль

`AfterglowUI.ts` и стили (`afterglow.css`, теперь `girlhub.css`) перенесены из `src/ui/` в `games/girlhub/`, как интерфейсы Nitro Run и Last Convoy. Host их не импортирует, поэтому одиночный выпуск модуля меняет только исходники своей папки. Добавлены `GirlhubLayout.ts` (расчёт компоновки) и `girlhubText.ts` (английские подписи новых элементов для уже установленного host).

Модуль больше не подключает `caramel-carnival.css`. Классы кабины переименованы с общих `cc-*` на собственные `ag-*`. Причина: модули грузятся в одну страницу, и правила Caramel, в том числе с `!important`, остаются в документе после открытия Caramel или Nitro. Общие классы оставлены только там, где на них опираются код и тесты: доска (`cc-board`, `cc-cell`, `cc-reel`), `cc-stake`, `cc-spin`, `cc-tools`, `cc-footer`, диалоги. Затвор защищён от правил Caramel через `!important` с более высокой специфичностью.

В `games/girlhub/tsconfig.json` подключён `src/vite-env.d.ts`, как у Last Convoy. Без него модуль на текущем `main` не собирался: общий `RoyalGameArtwork.ts` импортирует изображение `.webp`.

## Визуальное направление

Чёрная студия, оранжевый свет софтбоксов, золото выигрыша, холодная вспышка фотосессии. Поле оформлено как видоискатель камеры с уголками рамки, кнопка вращения как затвор с диафрагмой. В фотосессии рамка поля, уголки, затвор и карточка камер становятся голубыми.

## Компоновка

`GirlhubLayout` выбирает профиль по фактическому размеру корня модуля после размещения чата и рассчитывает поле 6:5.

| Профиль | Условие | Композиция |
| --- | --- | --- |
| Широкий | ширина от 780 px, высота от 560 px | Слева логотип и героиня в полный рост с прогрессом второго образа и альбомом. В центре видоискатель и строка результата. Справа свет на ячейках со шкалой ×1…×4, камеры, WILD в кадре, «О бонусе». Внизу док: баланс, выигрыш, ставка с ручным вводом, затвор, скорость, «Авто», правила, настройки. |
| Портретный | остальные размеры | Полоса героини с фото и альбомом, три счётчика (свет, камеры, WILD), поле, строка результата, док под пальцем: баланс и выигрыш, ставка, «Авто», затвор, настройки. |
| Горизонтальный | ширина больше высоты, высота меньше 560 px | Поле, затем колонка героини, счётчиков и результата, затем пульт. |

При высоте широкого корня меньше 720 px скрываются пояснения карточек и подпись «Пробел». Узкий широкий корень сначала прячет переключатель скорости (меньше 1080 px), затем «Выигрыш» в доке (меньше 960 px). Компактный портрет (меньше 700 px) ставит героиню и счётчики в одну строку, альбом становится кнопкой-иконкой с подписью для чтения с экрана.

Ошибка, восстановление хода и подсказка кошелька показываются поверх строки результата и не закрывают поле и сумму раунда. Скорость, число автовращений, правила, история, музыка, звуки, громкость, голоса и показ без анимаций находятся в настройках. На широком экране скорость и правила продублированы в доке.

## Проверка

```bash
npm --prefix games/girlhub run build
node node_modules/typescript/bin/tsc --noEmit
npm run check:rtp
LAYOUT_API_PORT=2981 LAYOUT_WEB_PORT=5481 LAYOUT_ARTIFACTS_DIR=artifacts/work/girlhub-redesign LAYOUT_TASK_ID=girlhub-redesign LAYOUT_SCENARIOS=1 node --import tsx scripts/game-layout-preview.ts
```

В другом терминале с теми же портами:

```bash
LAYOUT_API_PORT=2981 LAYOUT_WEB_PORT=5481 npx playwright test --config playwright.game-layout-slots.config.ts --grep "studio-afterglow"
```

Результат для пакета `1.4.0-5fbff7493e2b`: сборка с RTP gate, полный TypeScript и `check:rtp` прошли. В подключённом host с чатом прошли сценарии «поле и действия без прокрутки» на восьми размерах и «настройки, Стоп и одна принятая ставка 0,10»: ровно одно списание 0,10 USDT, восстановление потерянного ответа без лишней ставки. Отдельно проверены альбом и фото с кабины на 393, 320 и 568 px без изменения кошелька, естественный вход в фотосессию и сама фотосессия на ПК, телефоне и горизонтальном экране. Ошибок JavaScript не было.

Тест компоновки обновлён: альбом и фото открываются с кабины, а не из панели настроек, а сценарий вращения при смене ориентации находит корень GIRLHUB по `.ag-game`.

Не запускались до конца:

- `album, photo and themed menu remain accessible on a phone` и `moving symbols retain their field through both phone orientations`. Они открывают Meme Overload, Caramel Carnival и Velvet Reign, а сборка этих модулей на текущем `main` падает с той же ошибкой типов изображения. Их модули в этой задаче не менялись.
- `girlhub-feedback.spec.ts`: два сценария останавливаются на старом порядке входа в host (поле «Почта» до выбора режима входа), третий получает от своей заглушки ответ, который не проходит проверку подтверждения хода. Файл сценария не менялся с 27 октября и отстаёт от текущего host и протокола операций.

Физические устройства, приятность звука и показ людям не проверялись.
