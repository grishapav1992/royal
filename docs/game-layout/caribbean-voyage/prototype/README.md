# Карибские сокровища: макет «Плавание», версия 2

Живой макет редизайна. Раунды считает неизменённый `src/shared/caribbeanTreasures.ts`, деньги и очки условные. Фон, пиратки и символы взяты из игры и деформируются в коде, маски воды и неба сняты с текущего фона. Пушка вылеплена и освещена в коде (`gun.mjs`), сундук, крюки и острова карты нарисованы кодом.

Сборка: `node bake.mjs <папка>`, `node gun.mjs <папка>` (нужен Chrome), затем `./build.sh <папка>`. Отдавать по HTTP.

Выигрышем показывается только раунд, где выплата больше принятой цены. Возврат части цены идёт без сабли, монет и плюса. Потерянный ответ не повторяет ставку: поле, баланс и ход остаются прежними до проверки.
