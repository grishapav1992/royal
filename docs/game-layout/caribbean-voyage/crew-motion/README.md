# Живая анимация пираток (отложено)

Пример на Изабелле и Фрейе от 26 ноября 2026, в игру не перенесён: владелец отложил новую анимацию, в игре остаётся прежняя. Страница сравнения: https://claude.ai/artifact/6GFWbajP54PSEE4PHvzWLb.

- `rig.ts`, `rigs.ts`: движок. Тело на изгибаемой сетке, лица шести выражений поверх, коса или платок на пружинной цепочке, серьга маятником, жесты выигрыша и бонуса заменяют руку по маске.
- `page.ts`, `page.html`: страница сравнения с нынешней анимацией.
- `rig/<id>/`: готовые слои и их положение в кадре 1024×1536 (`crops.json`).
- `source/`: картинки, сделанные через A6API (модель gpt-image-2.6-flare, `/v1/images/edits`), без потерь. `usage.log`: расход токенов, 19 платных запросов, один ответ потерян по таймауту.
- `tools/`: сборка слоёв (`bake.mjs`, `faces.mjs`, `lib.mjs`), запросы к A6API (`edit.sh`, `prompts/`), описание вырезки (`rigs/`).

Сборка слоёв: положить картинки из `source/` в PNG в папку `gen/` рядом с инструментами, затем `node faces.mjs <id> ...` и `node bake.mjs <id>`. Параметры вызова `faces.mjs` записаны в `rigs/<id>-features.json` и в истории ветки.
