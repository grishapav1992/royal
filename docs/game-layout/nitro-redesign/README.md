## Компоновка

Размер определяется свободной областью настоящего host после размещения чата. `NitroRunLayout` выбирает профиль по фактическим размерам корня модуля, а не по ширине браузера.

| Профиль | Условие | Композиция |
| --- | --- | --- |
| Широкий | ширина от 780 px, высота от 620 px | Логотип над приборами слева, поле сразу справа, общая консоль снизу. |
| Горизонтальный | ширина больше высоты, высота меньше 620 px | Компактные приборы рядом с полем, результат и управление в общей консоли справа. |
| Портретный | остальные размеры | Три прибора над полем, ставка и старт в нижней консоли. |

Барабаны сохраняют пропорции 6:5. `NitroRunLayout` вычисляет размеры единого кабинета по доступным ширине и высоте: размер поля, приборов, заголовка и консоли согласованы заранее. Между приборами и полем остаётся один зазор 12 px. В широком профиле логотип занимает место над приборами, отдельной растянутой полосы заголовка нет. Консоль совпадает с общими левым и правым краями приборов и поля. Результат находится внутри консоли, без отдельной пустой полосы на фоне города.

Настройки, скорость, звук, правила и история находятся в одном диалоге. Старт, автоигра, текущая ставка и баланс доступны в консоли. Ошибка и восстановление показываются поверх строки результата, без изменения размеров поля. Чат и навигация остаются под управлением host.

При высоте области менее 570 px портретный профиль сокращает заголовок и строку результата. Это освобождает место для поля на экранах 320×568. В низком горизонтальном окне бонусный диалог использует компактную иллюстрацию и закреплённую кнопку продолжения.

Исходные мобильные снимки для сравнения: [портрет](../slots/studio-nitro-run-393x852.png), [альбомный экран](../slots/studio-nitro-run-852x393.png). Финальный вариант: [ПК с чатом](desktop.webp), [телефон](phone.webp), [горизонтальный экран](landscape.webp), [компактный телефон](compact.webp). [Измерения восьми размеров](layout.json) содержат идентификатор проверенного пакета.

[Сравнение компоновки до и после](comparison.webp). При одинаковом host с чатом на экране 1440×900 рамка поля выросла с 639,59×535,66 до 773,59×646,98 px. Прирост ширины около 20,95%. Между приборами и полем теперь 12 px; верхняя и нижняя части составляют один кабинет с общими краями. Это измерения компоновки, а не оценка удовольствия от игры.

## Панель автоигры

«Авто» открывает отдельную модальную панель. Игрок выбирает 10, 25 или 50 платных вращений, видит текущую ставку за вращение и сумму ставок за всю выбранную серию. Например, 25 вращений по 0,10 USDT дают 2,50 USDT, по 1,23 USDT дают 30,75 USDT. Сумма рассчитывается в целых центах.

Только отдельная кнопка «Запустить» начинает серию. Открытие панели, выбор количества, «Отмена», крестик и Escape не отправляют ставку. Сумма за серию не резервируется: каждое вращение оплачивается отдельно. При входе в бонус, ошибке, скрытии окна или недостаточном балансе авто останавливается. Кнопка «Стоп» отменяет следующие вращения, принятый раунд завершается по прежним правилам.

Нативный модальный диалог удерживает фокус и клавиатуру; стрелки переключают количество. Ставка блокируется до закрытия панели. Низкие горизонтальные экраны размещают количество и сумму рядом, сохраняя доступность запуска и отмены. [Панель на ПК](autoplay-desktop.webp), [на телефоне](autoplay-phone.webp).

## Карточка отклика

Звуковой движок и временная схема воспроизведения раунда сохранены. Изменения ниже относятся к представлению подтверждённого состояния. Это проектные решения, а не исследовательские пороги восприятия.

| Событие | Условие и отображение | Прерывание и проверка |
| --- | --- | --- |
| Нажатие старта | Существующее нейтральное вращение начинается параллельно запросу. Кнопка блокируется, подпись меняется на «Заезд». Новый результат до ответа не показывается. | Общая отмена playback при закрытии, скрытии и смене аккаунта. |
| Передача | Существующий `factor()` обновляет подтверждённый множитель, номер передачи, шкалу и стрелку. Переход стрелки до 400 мс является визуальной гипотезой этого оформления. | При reduced motion переход отсутствует. Число читается без движения и звука. |
| Заряд нитро | Два сегмента отражают `nitroCharge`; свечение включается существующим `data-charging`. Поле обозначает подтверждённую фазу нитро постоянной голубой рамкой. | Дополнительные циклические вспышки не добавляются. Восстановление состояния не запускает новый эффект награды. |
| Флаги и бесплатная серия | Существующие счётчики используют серверную историю. Во время бонуса пауза занимает место автоигры в консоли; число бесплатных вращений остаётся в бонусной панели. | Бесплатные продолжения сохраняют прежнюю принятую ставку. |
| Итог и потеря ответа | Точная сумма поступает из существующей сессии. Ошибка и кнопка проверки не перестраивают поле. | Повтор использует прежнюю операцию, переоткрытие не создаёт дополнительного списания. |

## Проверка

Команды:

```powershell
npm --prefix games/nitro-run run build
node node_modules/typescript/bin/tsc --noEmit
$env:LAYOUT_API_PORT='2979'
$env:LAYOUT_WEB_PORT='5479'
$env:LAYOUT_ARTIFACTS_DIR='artifacts/work/nitro-run-redesign'
$env:LAYOUT_TASK_ID='nitro-run-redesign'
$env:LAYOUT_SCENARIOS='1'
node --import tsx scripts/game-layout-preview.ts
```

В другом терминале с теми же портами и папкой результатов:

```powershell
npx playwright test --config playwright.nitro.config.ts
```

Проверка выполняется в настоящем host с временной PostgreSQL и локальными аккаунтами. Размеры: 1440×900, 1280×720, 768×1024, 1024×768, 393×852, 852×393, 320×568, 568×320. Сценарии проверяют отсутствие прокрутки и перекрытия управления, устойчивость поля при смене статуса, доступность настроек, автостоп, одну принятую ставку 0,10 USDT, восстановление операции и переоткрытие.

Физические устройства и субъективная приятность звука в этой задаче не проверялись. Общий production-граф был недоступен по SSH; связи проверены по исходникам текущего `origin/main`. Публичная проверка после установки сверила обе версии пакета, общий клиент и готовность сайта.

Итоговая проверка пакета `1.2.2-2551448802c8`: сборка с RTP gate и полный TypeScript прошли; 5 сценариев Chromium в подключённом host прошли без повторов и пропусков, включая открытие и закрытие мобильного чата без сдвига поля. Проверены панель автоигры на восьми размерах, точная сумма при ручной ставке 1,23 USDT и максимальной ставке 50 USDT, клавиатура, отмена и недопустимый черновик ставки. До отдельного запуска панель отправила ноль платных запросов; запуск со ставкой 0,10 USDT и последующий «Стоп» дали ровно одно списание. Отдельный сценарий общего кошелька при переключении модулей прошёл. Проверены 42 входа компиляции и 44 Git-источника проекции. На точных байтах клиента и backend с сайта, с временной PostgreSQL и локальным перенаправлением production-маршрутов, прошли все пять сценариев. [Английская панель](autoplay-english.webp) проверена с установленным словарём host; её новые подписи входят в модуль. Полная бонусная серия завершается с единственным начальным списанием. [Машинный отчёт](verification.json).

При проверке исправлены две ошибки тестового управления: чтение сессии через повторный импорт Vite давало устаревший экземпляр клиента, а ручной клик мог конкурировать с автоматическим завершением бесплатной серии. Проверка теперь читает настоящий host и возобновляет поставленную на паузу серию один раз. Игровой транспорт и серверная математика для этого не менялись.
