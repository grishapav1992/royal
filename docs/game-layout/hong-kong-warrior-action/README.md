# Гонконгский воин: большая драка

Представление игры `original-jackie-chan` в модуле `@royal/jackie-chan` 1.3.0. Контракты host/rules/progress 1/1/2 прежние. Утверждённый макет: [Гонконгский воин: Большая драка](https://claude.ai/artifact/6Bj5otEGWczQZNMgEHcyQx), исходники в `prototype`. Статус: локальная версия, на production не опубликована.

Стиль сохранён: рисунки героя и соперников, три локации, предметы, Impact, палитра, музыка. Новых изображений нет. Ставки, шансы 75/60/45%, выплаты, коллекция, кошелёк, протокол и серверные правила не изменились. Зрителей на заднем плане нет: пользователь их отверг.

## Состав

| Файл | Назначение |
| --- | --- |
| `JackieTrack.ts` | Дорожки движения. Состояние зависит только от сценария и времени |
| `JackieFight.ts` | Сценарий боя: выбор приёмов, обмены, завершающие удары, поражение, финал |
| `JackieArt.ts` | Вырезание рисунков, точка удара и контур по самому рисунку |
| `JackieEffects.ts` | Вспышки, дуги, пыль, щепки, посуда, фрукты, иероглиф |
| `JackieScene.ts` | Кадр, камера, свет, переход между боями |
| `JackieAudio.ts`, `JackieFightSounds.ts` | Звук по тем же событиям, добавлены треск дерева и посуда |
| `JackieUI.ts`, `jackie.css` | Интерфейс |

Удалены `JackieChoreography.ts`, `JackieFightPlans.ts`, `JackieOpenings.ts`, `layout.css`, `priorities.css`.

## Бой

Сценарий строится из ID серии, номера боя, локации и состава. Исход добавляется только в завершающий контакт: до него движения бойцов, камера, эффекты и звук победы и поражения совпадают. Выбор приёмов не зависит от размера окна, поэтому поворот телефона не меняет идущий бой.

Обменов 28, из них шесть коротких связок, пять с двумя соперниками и три с предметом. Завершающих приёмов 16, шесть из них с предметом локации. Бой длится 4,3 / 6,7 / 9,2 секунды. В среднем 8, 15 и 22 удара и уклонения. Это проектные параметры, а не пороги восприятия.

| Событие | Условие | Изображение | Звук | Прерывание |
| --- | --- | --- | --- | --- |
| Запрос | Нажата кнопка боя | Хлопушка открыта, исход не показан | Музыка локации | Ошибка и закрытие убирают хлопушку |
| Начало боя | Подтверждённый бой | Хлопушка щёлкает, прежняя группа уходит, новая вбегает, герой идёт с последнего места | Без акцента | Скрытие показывает итог |
| Контакт | Удар сценария | Замах, остановка на ударе, отлёт, вспышка. Крупных вспышек не больше трёх в секунду и на 2× | Кулак, нога, блок, дерево | Пауза звука продолжает с текущего места |
| Завершающий удар победы | Последний соперник | Иероглиф, короткая дрожь, замедленный полёт | Самый громкий контакт | Уменьшенное движение: статичный итог |
| Поражение | Подтверждённая потеря | Удар остановлен, герой отлетает в мебель, разводит руками | Удар, треск, падение | Без празднования |
| Победа в серии | Пять побед | Кулак, поклон, свет, конфетти 2,6 с, кнопка «Пропустить праздник» | Прежняя фраза | Повтор ответа не празднует снова |
| Выплата | «Забрать» | Поклон 1,1 с | Прежние три ноты | Нового боя нет |

## Экран

Управление снизу во всех размерах, боковой колонки нет. Карточка результата имеет постоянное место сверху, герой не дорастает до неё. Полоса серии показывает пять дублей, приблизительный коэффициент и сумму. Локация выбирается картинкой. На телефоне звуки, музыка и правила лежат в настройках. Подписи не мельче 11 px.
