# GIRLHUB: редкость образов и прогресс от ставок

Идентификаторы героинь сохранены. Героини открываются в порядке редкости: обычная Мия, редкая Наоми, эпическая Ева, легендарная Алиса. Пороги хранятся на сервере в сотых долях тестовой монеты.

| Героиня | Второй образ | Сумма принятых ставок с героиней |
| --- | --- | ---: |
| Мия | Обычный | 1000 монет |
| Наоми | Редкий | 2000 монет |
| Ева | Эпический | 3000 монет |
| Алиса | Легендарный | 4000 монет |

Одна монета ставки даёт одно очко прогресса. Выигрыш, проигрыш, наряд и размер выплаты не меняют начисление. Весь оплаченный раунд с бесплатными продолжениями считается один раз после окончательного расчёта. У каждой героини отдельный прогресс. На экране показывается полоса и статус, без числовых счётчиков, процентов и нумерации редкости.

Общий альбом развивается от суммы ставок: Мия доступна сразу, Наоми после 160 монет, Ева после 440, Алиса после 900. Каждый следующий порог включает открытие всех предыдущих героинь. Смена героини не обнуляет прогресс. Настройка порогов не затрагивает математику слота.

Однократная миграция afterglow-stake-progress-v3 добавляет три отдельные таблицы. Старые карточки преобразуются с сохранением доли заполнения альбома, старые вращения с сохранением доли заполнения каждой полосы. Коэффициент переноса: 20 монет за прежнее деление. Открытые ранее образы полностью сохраняются. Подтверждённый исторический оборот используется, если он больше пересчитанного прогресса. Для прежних партий без записанной героини персональный прогресс не придумывается. Существующая миграция v2 не менялась.

Исторические завершённые раунды записываются в отдельный журнал. Уникальный ключ аккаунт плюс раунд защищает от повторного начисления. Повреждённая историческая ставка прерывает миграцию целиком. Новое начисление, итог раунда, кошелёк и журнал операции фиксируются в одной транзакции под прежней блокировкой аккаунта.

Профиль оформления имеет version 4. Новый клиент передаёт X-Royal-Afterglow-Progress: 4. Старый клиент должен обновить страницу перед новой ставкой; принятые операции можно повторно подтвердить, а сохранённый бонус завершить. Формат математической партии и версия правил не менялись. После активации v3 требуется совместимое исправление вперёд, без возврата старого backend и без восстановления рабочей базы.

## Порядок открытия v4

Для прежнего выбора стартовой Алисы при недостаточном прогрессе используется Мия. Накопленные очки, общий прогресс и заработанные вторые образы не удаляются и не пересчитываются. Принятый до обновления бонус сохраняет свою героиню до окончательного расчёта; её ставка учитывается один раз в прежнем персональном прогрессе. После завершения применяется новый порядок. Переход не требует миграции таблиц.

Версия математических правил остаётся 2. Профиль RTP регистрируется отдельно с целью 0,96, допуском 0,01 и верхней границей 95% интервала не выше 0,98. Квалификация включает 10 миллионов полных оплаченных раундов с независимыми seed, все бесплатные продолжения, 13 разрешённых ставок, целочисленные выплаты и сверку с сервером. Точные наблюдения находятся в docs/game-math/qualifications/girlhub-progress-v4.json. Оценка по симуляции не является аналитически точным RTP.
