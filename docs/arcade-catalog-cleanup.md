# Компактная коллекция первого этажа

16 октября 2026 года. Запрос: убрать лишние автоматы и собрать оставшиеся рядом, сохранив второй и третий этажи.

В первом этаже 17 входов: Cosmic Escape, Caramel Carnival, Velvet Reign, «Последний конвой», 11 исходных адаптаций GitHub, Casino API Pro и внешний демокаталог Luelon. Упоминание GitLab уточнено пользователем: речь о GitHub. Hi-Lo относится к ранее снятым карточным играм и не возвращается.

Из каталога и физического зала убраны 32 прежние студийные игры и 13 собственных некарточных вариантов. Всего убраны 45 логических игровых входов, в том числе 36 физических автоматов. Переключатели собственных вариантов в исходных играх тоже удалены. Внешние каталоги продолжают содержать свой набор игр.

## План этажа

Два внешних каталога стоят у входа (480,330 и 480,550). Четыре новые игры стоят в одном ряду (1200..1860,330). GitHub игры находятся ниже, в пределах 1200..1920 по горизонтали и 550..1050 по вертикали. Удалены указатели и перегородки дальнего крыла. Размер мира не меняется, все зоны и препятствия второго и третьего этажей сохранены. Подходы и сиденья всех оставшихся автоматов доступны из начальной точки.

## Кошелёк и сохранённые партии

Математические движки, версии правил, таблицы выплат, генератор случайных чисел и схема базы не изменены. Не удаляются записи партий, история операций, резервы и балансы. Общий кошелёк остаётся прежним.

Новый старт снятой игры получает HTTP409 до списания и RNG. Уже принятый запрос с прежним UUID возвращает сохранённый результат; изменение запроса с этим UUID запрещено. Ходы старой активной партии продолжают работать по прежним правилам с одной итоговой выплатой.

Для активных сохранённых партий снятых игр есть отдельный раздел «Завершить сохранённое». Открытие проверяет текущий аккаунт и точную партию после обновления с сервера, не требует удалённого физического автомата. В этом окне новые старты блокируются; после завершения доступен результат. Смена аккаунта закрывает окно. Неподтверждённый запрос можно проверить с исходным UUID.

## Проверка

Четыре проверки состава, доступности маршрутов и неизменности этажей. Шесть проверок настоящего PostgreSQL кошелька, включая все 45 снятых игр, старые принятые запросы, завершение партий, повторные ходы, резервы, SDK и оставшиеся игры. Восемь целевых проверок клиентского восстановления. Отдельное ревью клиентского пути без найденных дефектов.

Браузерная проверка и доказательства публикации находятся рядом со stage в proof. Локальные catalog-qa файлы находятся вне production source roots и не включаются в выпуск. Разделение игр на независимые модули приостановлено по последнему запросу пользователя.
