# Первичные источники для исследования математических моделей

Дата проверки: 7 октября 2026 года.

## Источник случайных чисел и отображение результатов

[Официальный исходный текст документации Node.js, crypto.randomInt](https://github.com/nodejs/node/blob/main/doc/api/crypto.md#cryptorandomintmin-max-callback).

Документация задает полуоткрытый диапазон min <= n < max, сообщает об устранении modulo bias, ограничивает ширину диапазона значением меньше 2^48 и требует безопасных целых границ. Для предлагаемой модели U из 1..2^32 возможный вызов API имеет границы min=1 и max=4294967297. Это пример выбора диапазона, игровой сервер в рамках исследования не реализован.

Веб-версия документации на nodejs.org при проверке не загрузилась. Содержание раздела randomInt было проверено через официальный репозиторий nodejs/node и его [исходный Markdown](https://raw.githubusercontent.com/nodejs/node/refs/heads/main/doc/api/crypto.md).

[NIST SP 800-90A Rev. 1](https://csrc.nist.gov/pubs/sp/800/90/a/r1/final) описывает механизмы детерминированного получения случайных битов на основе хеш-функций и блочных шифров. Этот документ относится к генерации случайности. Он не удостоверяет математическую модель игры, честность ее оператора, правильность денежного учета или сертификацию проекта Royal.

## Границы выводов исследования

Crash / Limbo в scripts/game-math/crash.mjs рассматривается как наша предложенная независимая модель: R=97/100, Q=2^32, равномерный целочисленный U из 1..Q, C_raw=R*Q/U и отдельный instantLoss для C_raw<1. Формулы хвостов и ковариации выведены из этой модели, а не взяты из закрытой математики Aviator.

Точные расчеты рациональными числами проверяют дискретизацию, округление, правила равенства, предел коэффициента, ковариацию выплат и пример modulo bias. Дополнительно выполнен независимый исчерпывающий перебор всех U=1..10000. Полный перебор 2^32 входов и аудит будущего игрового сервера не выполнялись.

Детерминированные расчеты не проверяют качество фактической энтропии, непредсказуемость server seed, протокол его раскрытия, постоянство правил между раундами или обработку сетевых запросов. Эти требования остаются отдельной работой перед запуском игры.
