# Mira motion revision 3

The user rejected the movement quality of revision 2. Its functional checks did not establish animation quality. The articulated cutout renderer and its independent limb transforms have been removed. This revision uses 56 complete painted poses: eight walking, eight seated/standing, sixteen work poses, sixteen conversational poses and eight drink-preparation poses. It is a local revision for visual review, with no claim of user acceptance.

Every frame includes the connected torso, arms, wrists, face and relevant props. Runtime composition crops the original RGBA cells, applies one scale per sheet and uses the existing room-owned action progress. It does not stretch individual bones, draw a mouth over the face or run independent animation timers. The frame registration ignores nearly transparent edge noise. Each sheet retains its original alpha and resolution.

The seat sequence uncrosses the legs, braces the hands, shifts weight and settles behind the counter; sitting plays the same poses in reverse. An interrupted partial seat keeps the same pose and world anchor. Walking uses eight opposite-leg contact and passing poses. Wiping uses connected hand/cloth poses with a separate mask for tabletop contact. Polishing and stocking use their own complete drawings. Drink preparation progresses from lifting through tipping, pouring, replacing and presenting, then holds its final pose. Greeting raises and lowers one hand; listening stays quiet; replies use restrained painted gestures.

Only the seated lower body and wiping contacts pass over the counter. The board, flowers and coffee now occlude staff as complete objects, avoiding the old horizontal cuts through a moving body. The permanent cat mug remains a separate object at depth 513, above the character foreground at 510. Its position, approach, perch and drinking route are unchanged by the feature.

The drawings were made with the built-in imagegen tool. Their exact prompts and reference paths are in [generation.json](../public/assets/royal-bar/v3/generation.json). Final assets are [mira-walk.png](../public/assets/royal-bar/v3/mira-walk.png), [mira-seat.png](../public/assets/royal-bar/v3/mira-seat.png), [mira-work.png](../public/assets/royal-bar/v3/mira-work.png), [mira-react.png](../public/assets/royal-bar/v3/mira-react.png) and [mira-serve.png](../public/assets/royal-bar/v3/mira-serve.png).

Run `node scripts/royal-bar-art-review.mjs` and open `http://127.0.0.1:5198/?offline=1`. The action selector demonstrates individual sequences. Opening the dialogue returns to the ordinary room routine. Replies in the standalone viewer are scripted. The comparison viewer uses the previously reviewed host projection with the current bar renderer; it is not a production release. The final report records the exact test composition and source identity.

TypeScript and nine animation/presentation tests passed. The current cat climb, drink and exit test passed. The real-room capture checks eight action demonstrations, ordinary dialogue, closing and a mobile viewport, with no JavaScript or asset errors. Browser checks use a real isolated backend, disposable PostgreSQL, connected room chat and stubbed provider replies. Visual approval remains the user's decision; complete drawings and technical checks alone do not prove pleasing movement.
